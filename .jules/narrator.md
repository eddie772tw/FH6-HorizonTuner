## 2025-02-25 - Diagnostic Console & Confirmation Dialog Translations
**Learning:** Hardcoded destructive confirmation dialogs (e.g., `window.confirm(t("Are you sure you want to reset all HUD settings?"))`) and new developer tooling UI elements (like the Diagnostic Console) are prone to missing translations in secondary locales (`ja-jp.json`, `zh-tw.json`), resulting in fallback to English for non-English users.
**Action:** Always scan for unmapped `t()` calls in newly added components and ensure destructive or critical UI feedback strings are fully populated across all supported active locales.
