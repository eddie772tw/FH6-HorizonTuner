## 2024-05-24 - Canvas 2D Scatter Plot Optimization Reversion
**Learning:** While batching `rect()` into a single `fill()` reduces state changes in Canvas 2D, doing so for overlapping translucent shapes (like in a scatter plot) breaks `source-over` alpha accumulation. The overlapping areas will not compound in opacity, resulting in a loss of visual density information.
**Action:** NEVER batch overlapping translucent shapes using `ctx.rect()` + `ctx.fill()` when visual density is required. Instead, use individual `ctx.fillRect()` calls inside the loop. The CPU cycle optimization can still be achieved by avoiding modulo arithmetic (`%`) in tight loops.
