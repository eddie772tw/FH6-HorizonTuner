## 2024-05-19 - Accessible Tooltips for Disabled Buttons
**Learning:** In React, tooltips on disabled buttons are inaccessible to keyboard and screen-reader users because disabled elements are removed from the document tab order. Wrapping them in a `span` doesn't help unless the wrapper itself is focusable and identifiable. Furthermore, disabled buttons swallow mouse hover events, preventing tooltips from appearing on mouseover as well.
**Action:** When adding tooltips to disabled buttons, always wrap the button in an element (like a `span` or `div`) that includes `tabIndex={0}`, `role="group"`, and `aria-label="..."`. Crucially, set `style={{ pointerEvents: 'none' }}` on the disabled button itself, and handle the cursor style (`cursor: 'not-allowed'`) on the wrapper.
