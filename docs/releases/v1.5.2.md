## What's New
* **分析視圖賽後簡報與 MoTeC 生態增強 (AnalysisView Post-Race Debrief & MoTeC Enhancement)**：全新賽後遙測分析簡報引擎，包含圈速穩定性分析、極限過彎動態評估與 MoTeC CSV/LD 匯出格式相容性強化 (#290)。
* **S650 HMI 系統媒體播放組件與中央資訊可讀性優化 (System Media Music Widget & Readability)**：新增全域 Windows 系統媒體 (GSMTC) 音樂小工具與歌曲資訊即時顯示，並全面引入 15% 半透明深色遮罩設計權杖，大幅改善在 Forza 遊戲強光動態背景下的儀表資訊對比度與易讀性 (#296)。
* **Step 5 遙測閉環調校增強 (Tuning Step 5 Closed-Loop & Event Notifications)**：Step 5 閉環回歸可編輯調校參數設定表格、測試圈動態事件累積通知匣與多重調校衝突仲裁引擎，提供直覺的數據導向參數微調 (#292)。
* **MCP 伺服器標準化初始化指引 (Standard MCP Initialization Guidance)**：強化 Model Context Protocol (MCP) 整合引導與設定說明，支援第三方 AI 工具更無縫對接 HorizonTuner 遙測與調校資料庫 (#297)。

## What's Fixed
* **60Hz 渲染迴圈 GC 壓力消除與佈局幾何快取**：Drift HUD 改為在視窗尺寸變更時預先計算幾何錨點，消除了每秒 120 次以上的暫態物件配置與佈局數學運算 (#303)；即時地圖 (Live Map) 消除展開運算子中介陣列配置 (#300, #295)；儀表車速顯示全面引入 DOM pooling 機制 (#291)。
* **大數據集展開運算子堆疊溢位防護**：重構 LapDeltaCanvas、rallyProfile 與 roadProfile 中多圈萬點遙測陣列之極值計算，由 `Math.max(...arr)` 全面升級為線性迴圈，徹底根絕 V8 引數數量限制引發的 `RangeError: Maximum call stack size exceeded` (#301)。
* **診斷支援包與日誌主控台多語系本地化**：完整補齊本機診斷支援包 (Diagnostic Support Bundle)、日誌主控台 (Log Console) 與 Data Out 設定指引彈窗之 i18n 多語系翻譯 (#299, #302)。
* **UI 無障礙體驗提升**：在更新 Modal 引入無障礙非同步載入旋轉器 (Async Button Spinner) (#298)，並為所有停用狀態按鈕提供友善可訪問的 Tooltips 操作提示 (#294)。
* **Tauri 開發編譯加速與啟動協同重構**：開發模式下排除大型 Sidecar 搬移並啟用 LLVM `rust-lld` 多執行緒連結器，增量建置時間由 20 秒驟降至 1 秒以下；重構 `start_all.bat` 與連接埠就緒門控 (Readiness Gate)，消除啟動競態、舊端口幽靈就緒與動態埠回退問題。
* **執行檔檢查動態契約化**：CI 與發行驗證腳本全面改為從 Runtime 來源動態衍生版本比對，消除硬編碼斷言。
