## 版本與來源

- Runtime SSOT：`frontend/src-tauri/tauri.conf.json`，同步兩個 Cargo package 與各自 lock 的本地 package entry；不變更其他 resolved dependencies、歷史 capture／golden 或 Android versionCode。
- `backend-rust/build.rs` 依 runtime 產生 PE metadata；編譯成功與 PE 值實際可讀是不同檢查。
- 發布候選應凍結在此準備 PR 合併後、通過新 main CI／CodeQL 的精確 SHA。記錄來源 SHA／tree、workflow URL／artifact ID、檔案 SHA-256、PE／runtime 與 updater manifest，不能只選當時最新的浮動 main。
- 建置順序：完成新 frontend dist，再編譯／stage backend sidecar，最後建立 Full／Lite host；Full 與 Lite 使用同一 target 輸出名稱，必須分別保存。
