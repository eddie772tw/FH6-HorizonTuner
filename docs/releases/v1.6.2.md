# HorizonTuner v1.6.2 Release Notes

## What's New

* **AEGO 自動化引擎與齒比優化演算法升級 (AEGO EV & ICE Foundation)** (#445, #446)：
  - **獨立純電 (EV) 遙測量測與齒比計算基礎** (#445)：建立純電車輛專屬動力測量機制，支援單速與多速齒比計算。
  - **連續斷油特徵與極限轉速循環辨識** (#445)：新增斷油切斷與恢復循環 (Limiter Cut-Recovery Cycle) 辨識邏輯，在轉速衰減前錨定極限轉速，徹底解決低功率與特殊轉速特性車輛之適配問題。
  - **公路齒比聯合求解 (Joint Road Gearing Solver)** (#445)：重構 Road 齒比計算器，自動過濾彈射起步暫態峰值，阻擋物理不可行之極端齒比建議。
  - **16:9 齒比匹配曲線圖表** (#445)：齒比圖表升級為 16:9 寬螢幕比例並擴充檔位列表顯示。
  - **純電與燃油工作流聯合型別契約修復** (#446)：解耦並統一 EV 與 ICE 在前端算牌工作流中的聯合型別定義。

* **產品後端獨立 Rust 核心全面加固與 Python 執行環境正式除役** (#443)：
  - **Python 產品後端正式退休**：完全移除產品路徑中的 Python 後端執行期，全平台全面由高效能獨立 Rust 二進位 (`fh6-backend` / `server-sidecar`) 提供服務。
  - **高頻遙測查詢與序列化零拷貝優化**：重構 API 遙測讀取範疇，消除逐影格資料庫複製與非必要 JSON 記憶體拷貝，大幅降低高頻資料流傳輸延遲。

* **跨平台 Linux Full AppImage 發行與維護架構確立** (#426)：
  - **Linux x86_64 AppImage 支援**：新增 Ubuntu 22.04 基線之 Linux AppImage 發行建置與 OTA 簽章流程。
  - **平台邊界清晰化**：明文化 Windows (Full/Lite) 與 Linux (Full AppImage) 之平台支援矩陣，移除歷史 macOS 未支援代碼與發行通道。

* **高頻 60Hz 遙測與繪圖極致效能優化 (Hot Path Performance)** (#437, #449, #451, #453)：
  - **Session Debrief 純量累加優化** (#451)：將前端 Session 報告統計改寫為單次迴圈內純量累加，消除大量陣列配置與 `.map()` / `.reduce()` 鏈式呼叫，顯著降低長時記錄處理時的 GC 抖動。
  - **Canvas 顏色解析快取與快速捷徑** (#453)：在 60Hz Canvas 圖表繪製迴圈中為 HEX 與 RGB 色彩字串加入 O(1) 前綴捷徑，大幅降低正規表達式與 `getComputedStyle` 開銷。
  - **輪胎特徵觀測迴圈展開** (#449)：手動展開輪胎數據過濾與累加操作，消除高階函式閉包分配。
  - **二進位封包打包迴圈優化** (#437)：消除 60Hz UDP 封包解碼與打包循環中的動態 List 記憶體配置。

* **UI / UX 佈局整合與視覺體驗** (#438, #439, #444)：
  - **桌面端抽屜與 Live 佈局統一** (#438)：整合 HUD 與全域應用選單，引進桌面端自適應抽屜 (Adaptive Desktop Drawers) 與統一的設定介面。
  - **磁帶羅盤高解析度繪製** (#444)：將 Tape Compass HUD 升級為原生顯示解析度渲染，消除文字與刻度模糊問題。
  - **按鈕禁用狀態提示** (#439)：為禁用的 HUD Setup 按鈕補齊 Tooltips 說明。

* **安全性強化 (Security Hardening)** (#450)：
  - **[MEDIUM] 確保刪除 Session 時完整清除孤立資料** (#450)：在 SQLite 交易中明確遞歸刪除 `telemetry_channels` 與 `laps` 子表紀錄，防止連線未啟用外鍵級聯時造成敏感遙測資料殘留。
