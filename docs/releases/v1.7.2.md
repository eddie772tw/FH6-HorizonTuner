# HorizonTuner v1.7.2

**狀態：發行候選準備；runtime 11.45.22。** 本版整合自 v1.7.1 以來的介面、HUD、賽事分析與調校工作流更新，也納入尚在開發的基礎能力。下方 WIP／Known Issues 保留其實作與驗收界線；本文件不代表已發布安裝檔或完成公開 OTA 升級。

## 新增與改善

- **HUD 與主題選擇**：新增 AP1 Rev Arc、LFA Center Ring、Stack ST8100 與 R34 MFD HUD，補上各自的設定與顯示契約；加入 Swiss Technical／Editorial／Contrast 及 Rhine Lab 主題與對應圖表樣式。這些是本版新增的介面能力，並非新增自動駕駛或調校公式。
- **Live 遙測效能與圖表**：改用增量輪胎溫度直方圖，減少離屏卡片的繪製工作；遙測與歷史仍持續接收，卡片重新進入畫面時顯示最新資料和單位。修正懸吊歷史截斷並統一靜止時圖表更新，改善 HUD／圖表色彩快取及切換單位後的最高速度顯示。效能改善不等同所有電腦都達成固定 FPS 或倍數提升。
- **賽事分析與自訂路線**：計時賽可用同一起點閉合圈次；漫遊可設定起點與終點並在終點停止。路線需先武裝，缺少座標、時間倒退或資料缺口不會補造穿越或完整圈。可查看原始／有效區段、修剪結果，並匯入 CSV 作本地預覽與圈次分析。CSV 預覽不會自動建立已保存 session；可在 MoTeC 使用原始 CSV 檔案。
- **中性基準預覽與就地證據**：在既有 Rust 底盤／定位結果上顯示目前值、建議值、差異、缺項和可用欄位；提供草稿、取消與明確套用，並保護車輛、profile、目標及季節切換後的舊回覆。未知或不可調欄位保持 unavailable／locked。**套用只更新程式內的基準，不會寫入遊戲；建議值也不會被當成已確認的遊戲設定。**
- **CVT 基礎辨識與診斷**：新增明確的變速箱類型／能力選擇，建立帶來源的 CVT capture 資格、保存與冷讀契約，讓 CVT 分流不誤用既有 ICE／EV 採集器。這一版尚未提供 CVT 終傳 solver、ratio preview 或可套用推薦；通過 capture 資格只表示資料契約符合要求。
- **Companion 主題與原生字型基礎**：WebView 與 Android 外殼接收同一份受限主題設定，保留各連線 endpoint 的最後有效主題；新增原生 Outfit／Inter 字型資源與可離線閱讀的授權通知。原生與 WebView 的實際視覺一致性仍須裝置驗收，Rhine 原生字型目前保留 system SansSerif fallback。

## 修補與維護

- 補齊 Road 統計、更新來源、Companion 停用／掃描／連線理由與開發調校 Hz 標籤的翻譯；修正英文 Companion 顯示 `companion.*` 原始鍵的問題，同時保留繁中／日文既有用語及命令值。
- HUD 音訊刷新及 Companion LAN／USB 停用按鈕顯示狀態提示，保留原有停用、busy、未選裝置及選定 serial 的保護。
- 修正 Stack ST8100 溫度單位型別契約；改善已載入 session 的圈次聚合，保留不完整圈、未知圈速及原始來源語意。
- 更新前端、Rust 與建置相依套件，收斂 source-map-js 至修補版本 1.2.2，並減少 API 錯誤回應暴露原生細節。這些更新不代表所有平台與原生程式的安全驗收已完成。

四個 Issue 保持開啟，完成本次發行準備不會自動關閉它們。未完成的能力不會以猜測的車輛參數、來源時間或設定版本補值。

**MoTeC 原生匯出仍為實驗性。** 已錄製 session 可匯出 41 通道 CSV 與工作區 XML；`.ld`＋`.ldx` ZIP 尚未在真實 MoTeC i2 安裝中完成開檔及通道核對。本地二進位、60 Hz 重取樣與 Beacon 契約測試不能代替該驗收；不完整圈、未知圈界及跨缺口插值均受限制。

**Companion 安裝與產物界線。** Companion 是需 HorizonTuner Full 持續運行的 Android 13+ thin client。LAN 使用同一受信任網路與配對；USB 開發連線需要啟用 USB debugging 並接受 Android 授權提示。目前可核對的 CI Android 產物是 `app-debug.apk`；正式散發 APK 的來源、簽章、安裝／升級相容性及裝置矩陣仍須另外核對，不能將 debug build／字型檢查當作正式簽章與裝置通過。僅下載 APK 不會讓手機獨立執行調校計算或離線 HUD。
