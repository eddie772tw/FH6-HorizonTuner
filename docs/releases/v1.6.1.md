# HorizonTuner v1.6.1 Release Notes

## What's New

* **Android Companion App 行動端協同架構 (Beta)** (#425)：
  - **行動遙測與調校工作流**：全新原生 Android Jetpack Compose 輕量 App（位於 `companion/`），提供移動端專屬賽車數據儀表與即時算牌面板。
  - **雙模連線與配對支援**：支援區網 QR Code 一鍵配對 (LAN Pairing) 與低延遲 USB/ADB 連線生命週期管理。
  - **自適應窄螢幕佈局**：重構離線導航與連線狀態卡片，在小尺寸或短螢幕手機上維持極佳操作手感。
  - **發行合規加固**：完成 Google Play 審查標準合規加固與 PadLink 雙向協議對齊。
  > [!NOTE]
  > **Beta 階段發行說明**：本次發行仍專注於 Windows 桌面端產物，GitHub Release 產物中**不提供預編譯之 APK 安裝檔**。若欲搶先體驗行動端功能，請自原始碼專案目錄手動編譯（於 `companion/` 目錄執行 `./gradlew :app:assembleRelease` 或 `:app:assembleDebug`）。

* **獨立 Rust Sidecar 後端全面遷移與雙端契約修正 (Beta)** (#423, #424, #427, #428, #429, #430)：
  - **Rust 高效能核心遷移** (#424)：將產品後端執行時全面替換為獨立的 Rust Sidecar 二進位（`fh6-backend` / `server-sidecar`），大幅降低記憶體佔用與啟動延遲。
  - **跨平台輸出一致性與精確持久化** (#424)：重構 MoTeC 遙測導出協議與換行符處理；在 JSON 序列化與 SQLite 儲存層導入嚴格浮點數保真（`float_roundtrip`），徹底杜絕設定存取過程中的數值漂移。
  - **後端遷移契約修正與雙端 SSOT** (#423, #427, #428, #429, #430)：配合後端語言遷移，徹底釐清前後端責任，修正歷史計算契約：
    - **三層單位契約架構 (3-Tier Units Contract)**：明確劃分遊戲原生單位、SI 物理標準單位與 UI 顯示單位，修正 Turbo 渦輪壓力與增壓數值換算 (#427)。
    - **純 Rust `tuning_core` 實現**：將所有懸吊、阻尼比、防傾桿與齒比計算以純函數形式實現於 Rust 後端，並建立單元契約測試 (#429)。
    - **黃金固件數值驗證 (Golden Fixtures)**：建立 `tuning_golden_fixtures.json`，強制 Rust 後端與 TypeScript 前端在算牌結果上達到 100% 數值一致 (#428, #430)。

* **前端資訊架構 (IA) 全新改版與持久化工作區 (Beta)** (#339, #345, #405, #406, #407, #408, #410)：
  - **持久化工作區 Shell (Persistent Workspaces)**：導入全新的主控框架，支援在 Telemetry、Tune、Road 等功能工作區間無縫切換而不丟失進行中的狀態與記錄 (#345, #406)。
  - **Road 實車分析工作流保護**：新增工作流草稿保護機制與儲存回讀保護，防止非預期的即時數據覆蓋未儲存之調校設定 (#406)。
  - **HUD 控制邊界解耦**：將 HUD 儀表呈現層與狀態控制器明確拆分，提供獨立的 Setup Layout 與進階工作區面板 (#406, #407)。
  - **語意化設定介面**：將全域設定拆分為更具層次感的語意化設定表面 (#406)。

* **HUD 儀表覆蓋層增強與視覺優化**：
  - **磁帶式羅盤 (Tape Compass HUD)**：在遙測儀表群中新增復古航太風格的磁帶滾動羅盤覆蓋層 (#421)。
  - **G-Force 雷達自訂控制**：新增 G-Force 重力雷達儀表的對齊錨點、基準縮放比例與座標偏移調整 (#419)。
  - **棄用即時地圖遙測卡片**：將原先實驗性的即時地圖遙測卡片標記為棄用 (Deprecated) 並移除相關未使用的靜態資產 (#420)。

## What's Fixed & Performance

* **調校演算法與引擎特徵掃描修正** (#396, #397, #412)：
  - **斷油點特徵連續掃描修正**：分離正輸出採集與斷油特徵觀測，修復低斷油車輛零／負功率影格判定導致 Step 3 無法完成之問題，利用連續斷油特徵自動完成低限與極限轉速掃描 (#412, Closes #396)。
  - **馬力機形態與齒比圖表對齊**：依據引擎扭力輸出曲線特徵自動補齊轉速曲線，並將齒比匹配圖表精準對齊至斷油轉速 (#396, #397)。

* **高頻 60Hz 渲染與遙測計算極致優化**：
  - **O(1) 環形緩衝區渲染循環**：全面優化 Canvas 圖表渲染迴圈，徹底消除每秒重繪產生的暫態陣列與 GC 抖動 (#418)。
  - **公路分析分佈計算加速**：大幅優化路面顛簸與離散度統計演算法，降低長時記錄分析的 CPU 負載 (#416)。
  - **展開 4 元素插值與熱點迴圈**：展開 TelemetryDetailView 及數值插值中的小陣列方法，消除迭代器與閉包建立開銷 (#402, #409)。
  - **非同步 I/O 與內存快取**：將分析設定寫入等同步阻塞 I/O 卸載至執行緒池，並在記憶體中快取語系 JSON 降低檔案讀取次數 (#385, #386, #387, #395)。

* **重大安全性加固與路徑防禦**：
  - **目錄穿越防禦 (Path Traversal Guard)**：後端儲存路徑全面透過限定目錄解析校驗，阻斷潛在的路徑逃逸風險 (#424)。
  - **[HIGH] SQL 注入防禦**：徹底修復 TelemetrySQLite 中的動態查詢拼接隱患，改採標準識別碼正規校驗與參數化查詢 (#404)。
  - **錯誤訊息脫敏**：全域攔截並過濾 API 響應中的原始例外堆疊，避免內部路徑與系統資訊外洩 (#400)。
  - **原生另存新檔與導出彈窗**：整合桌面原生檔案儲存對話框，安全在介面保留後端導出錯誤通知並維持原分析畫面 (#413, Closes #391, #392)。

* **UI / UX、無障礙與多語系本地化 (i18n)**：
  - **狀態與比對標籤在地化**：補齊 Data Out 連線狀態標籤與公路比對文字參數化在地化翻譯 (#399, #403)。
  - **輪胎溫度標籤中文化**：提取並翻譯遙測視圖中內側、中央、外側輪胎溫度標籤 (#394)。
  - **表單無障礙關聯修正**：修復 DiagnosticConsole 診斷控制台之 Form Label 與 Input 的 ARIA 關聯 (#393)。
  - **清空佇列防呆確認**：為 Clear Feed 操作新增確認彈窗，防止誤觸清除即時遙測資料 (#350)。

* **基礎設施、測試套件與依賴治理**：
  - 統一 Dependabot 與 pnpm workspace lockfile 格式並更新 Python 依賴套件 (#414, #417)。
  - 整合前後端單元測試套件與程式碼健康重構 (#389, #390)。
