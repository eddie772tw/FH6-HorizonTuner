# HorizonTuner v1.7.1 Release Notes

## What's New

* **後端調校公式與責任契約全面收攏至 Rust (Rust Backend Tuning SSOT)** (#460)：
  - **Rust 單一真理責任確立**：經架構評估，由產品後端 Rust (`backend-rust/src/tuning/`) 成為所有影響車輛調校建議的公式、資格審查、預設值、物理限制、Readiness 與數值診斷之唯一擁有者 (Owner)。前端 TypeScript 舊模型全面凍結僅保留測試參考，生產環境拒絕 runtime imports，徹底消除雙端計算漂移。
  - **桌面端與 Companion 工作流結果共用**：重構 `TuneSessionProvider`，桌面端介面與行動 Companion 統一消費由 Rust 計算的調校工作流結果 (`/api/tuning/workflow`)，消除前端重複計算與分叉風險。
  - **Road 起步模型升級為版本化 Launch Envelope v3**：修復高扭力引擎車型在 Road 調校模型下的起步目標計算與退化問題，並保留低功率車輛與歷史模型相容性驗證 (#460, #462)。
  - **調校證據重播與安全邊界加固**：嚴格要求調校建議必須具備重播認證 (replay-qualified) 之後端證據 ID，阻擋前端直接傳送裸峰值或偽造瞬間數據；EV 遙測捕捉傳輸完整保留轉向 (steering) 數據。
  - **凍結歷史診斷模型與隔離唯讀分析**：將舊版 CLI/MCP 與桌面實驗模型分離並標記明確版本契約 (`legacy-cli/v1`、`legacy-mcp/v1`、`legacy-desktop-experimental/v1`)。

* **遙測熱路徑極致效能優化 (Hot Path Performance)** (#461, #463, #465)：
  - **Tape Compass 樣式計算快取** (#461)：在 60Hz 磁帶羅盤渲染迴圈中引入 `getComputedStyle` 樣式快取機制，大幅降低 DOM 樣式查詢開銷與重繪抖動。
  - **前端遙測迴圈展開** (#463)：手動展開頻繁調用的 `.slice(0, 4).every()` 鏈式判斷，消除暫態子陣列切割與高階函式回呼造成的 GC 壓力。
  - **readFour 效能路徑優化** (#465)：手動展開 `readFour` 中的 `Array.every()`，消除每影格的高頻迴圈回呼分配。

* **UI / UX 與多語系體驗改進 (UI/UX & Localization)** (#457, #464)：
  - **Reload HUD 載入狀態指示器** (#457)：在重載 HUD 按鈕上新增動態載入 Spinner，提供明確的非同步處理視覺反饋。
  - **MCP 標籤多語系國際化 (i18n)** (#464)：補齊 MCP 相關介面標籤與提示文字之多語系翻譯，並維持標準代理開發日誌契約。
