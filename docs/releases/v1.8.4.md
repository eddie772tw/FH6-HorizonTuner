## What's New

### HUD樣式更新 HUD Style Updates

新增了以下儀表樣式

- NFS Underground 2，支援多款盤面與雙指針顯示
- Toyota Supra MK4 TRD、Soarer Z20 VFD、Chaser JZX100 與 Altezza TRD
- AutoMeter Sport-Comp Monster、GReddy TRUST Sirius Tacho、Blitz Racing Meter SD、Defi Advance BF Tacho，以及 Speedhut Datsun 240Z Classic／Modern 六款獨立轉速表

### HUD設定工作區 HUD Settings Workspace

HUD 設定改為「主儀表／遙測卡片／一般／音響系統／輔助儀表」五個分頁，顯示、縮放與位置設定集中在對應區域。關閉元素後仍可預先設定，切換分頁會保留尚未提交的輸入與捲動位置。

### 獨立音響與輔助儀表 Independent Audio Head & Auxiliary Gauges

- 音響系統可與主儀表並存，提供九款主機、獨立縮放、四邊對齊與 X／Y 位移拉桿
- 輔助儀表提供 AEM、GReddy、Blitz、Defi 與 Speedhut 五款表頭，可複選並切換橫排或直排
- 增壓、油壓、油溫與水溫可集中設定共用數值來源；預設油壓為引擎負載估計，油溫與水溫使用平均胎溫，不是真實引擎感測值

### Companion連線控制 Companion Connection Controls

新增 Companion 主開關、USB／ADB 獨立開關與停止 ADB 功能。USB 預設關閉，開啟設定頁不再自動掃描裝置；需要 USB 連線時再手動啟用與重新整理。

## What's Fixed

- 修正 R34 MFD 版面空白與儀表繪製問題，MFD 顯示改由獨立開關控制
- 修正程式重啟後 HUD 顯示狀態可能與保存值不一致，避免 Live 工作區被錯誤暫停
- 修正音響與輔助儀表的縮放、排列、刻度及設定保存問題，保留原素材底圖與材質
- 強化齒比重分配、檔距上下限、配重、懸吊對稱及阻尼的異常輸入防護，並統一驅動形式判定
- 改善 G 力、輪胎、懸吊與轉速圖表的即時標記、邊界裁切與繪圖狀態隔離
- 減少 UDP 接收、賽事錄製、車輛識別與 Dyno 採樣路徑的資料複製及記憶體配置開銷
- 強化 localhost Host 驗證、HTTP 回應安全標頭、語系檔案路徑與長度檢查，以及 Companion 配對資料與裝置數量限制
- 修正停用 Companion 後既有 LAN 連線仍可使用的問題，並改善 USB／ADB 停用與清理流程
- 改善 MoTeC 欄位對照視窗的鍵盤焦點、更新下載期間的關閉防護，以及數值欄位與設定開關的無障礙語意
- 補齊手動錄製、調校採集、賽事狀態與修剪摘要的繁中、日文及英文顯示
- 升級了多個依賴元件或模組的版本
- 升級了多個 GitHub Actions 的腳本版本
