## What's New

* **全新改版 Tuning Workflow (V2) 與實車測試圈特徵驅動 (Overhauled Tuning Workflow V2 & Race Evidence)**：
  - **4 階段 3 欄位精簡佈局**：將調校流程全面精簡為 4 階段 3 欄位清晰佈局，整合即時賽車狀態與參數回饋 (#330)。
  - **實測遙測取代靜態胎質輸入**：徹底捨棄原先的手動輪胎抓地力係數輸入，改由真實操駕之輪胎載荷與遙測特徵（Race Evidence）自動觀察並驅動定位角度與胎壓求解 (#336)。
  - **Road 前驅底盤與 AEGO 扭力分配**：新增公路前輪驅動 (FWD) 底盤調校公式模型，並引入全電/混合動力 (AEGO) 前後軸獨立扭力分配計算 (#332)。
  - **拉力 (Rally) 與越野 (Cross Country) 基準分離**：獨立拆分混合路面拉力與大衝程越野的懸吊剛性、阻尼比與車高計算模型 (#334)。
  - **實測轉速區間衍生甩尾設定與全齒比**：根據引擎實際最大功率與扭力峰值轉速區間，自動推導甩尾 (Drift) 動態底盤與齒輪比 (#333)。
  - **完整直線加速 (Drag) 變速箱與終點時速推導**：支援專業直線加速變速箱各檔位齒比梯度計算，並以實測終點時速證據校正終傳比 (#335)。

* **全新 HorizonTuner-cli (`fh6-agent`) 命令列工具 (HorizonTuner-cli AI Agent Tooling)**：
  - 專為 AI Agent、自動化腳本與終端玩家打造的自包含命令列工具，零第三方 Python 依賴（僅標準庫）(#318)。
  - 具備**線上/離線雙模式**：線上模式直接透傳 UDP 遙測與 HTTP API 狀態；離線模式提供與 GUI 100% 同源的純數學求解與調校檔案讀寫。
  - 支援一鍵執行連接埠就緒探測（`status`）、即時動態診斷（`diagnose`）、車輛規格檢索（`spec`）與底盤算牌（`tune`），並提供 `--json` 機器可讀輸出與 dual launcher 協同工作流。

* **全新 Classic JDM 樣式儀表與社群 HUD 整合 (Classic JDM Cluster & Community HUD Styles)**：
  - **Classic JDM 儀表群組**：高對比度復古白底轉速儀表盤、超轉換檔提示燈、雙計程儀與渦輪壓力表，提供沉浸式 90 年代日系性能車儀表視覺 (#356)。
  - **街機多聯錶版面 (Arcade Multi-Gauge Layout)**：支援模組化多聯錶並排顯示，適應寬螢幕與透明浮動覆蓋層。
  - **標準化 1080p 響應縮放**：統一所有 HUD 儀表的座標錨點與自適應等比縮放機制，徹底根除不同解析度下的破圖與位移。
  - **5 款社群熱門 HUD 覆蓋層樣式**：整合社群廣受歡迎的儀表覆蓋層風格，並補齊契約測試與多語系切換支援 (#319, #5d41bdd)。

## What's Fixed & Performance

* **全域 60Hz 渲染路徑 O(1) 環形緩衝區與 GC 壓力徹底消除**：
  - 遙測卡片全面導入定長 O(1) 環形緩衝區（Circular Buffers）取代舊有 `Array.shift()`，徹底根除每秒高頻陣列複製重排帶來的 GC 卡頓 (#355, #327)。
  - 消除遙測陣列處理中多處 `Math.max(...arr)` 展開運算子堆疊負擔與暫態陣列記憶體配置 (#357, #329)。
  - 重構 `calculateSuspensionMetrics`、`SurfaceRumble` 與 session debrief 中的陣列操作，展開迴圈消除 `Array.from().map()` 與 Set 迭代器開銷 (#352, #353, #338, #326, #321)。
  - 整合遙測欄位多重冗餘過濾，改為單次遍歷的 `useMemo` 迴圈處理 (#316)。

* **重大安全性漏洞防禦與加固**：
  - **[CRITICAL] 自訂公式任意程式碼執行防禦**：徹底修復自訂數學計算引擎中的潛在代碼執行漏洞，引進 AST 白名單沙盒與語法嚴格校驗 (#351)。
  - **DDL SQL 注入防禦**：修復 SQLite 資料庫 DDL 語句拼接漏洞，改採嚴格參數化與識別碼白名單轉義 (#322)。

* **UDP 封包預編譯 struct 解析優化**：
  - 遙測監聽模組引進預編譯二進位 struct 解構器，大幅提升 60Hz+ 高頻遙測封包解析輸送量，降低 CPU 佔用率 (#328)。

* **開發啟動協同重構與多語系本地化完備**：
  - 重構本地開發環境啟動流程與 WSAPI 連線穩定性 (#331)。
  - 全面檢視並補齊 ARIA 無障礙標籤、滑桿數值提示與視窗關閉按鈕之多語系本地化翻譯 (#317, #320, #337, #358)。
  - 治理規範與 Skill 體系模組化精簡重構 (#325)。
