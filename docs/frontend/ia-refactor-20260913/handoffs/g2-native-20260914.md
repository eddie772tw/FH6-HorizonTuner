# G2 Windows 原生驗收交接

日期：2026-09-14。準備者：IA Coordinator as Codex；程序來源審查：Terra。

狀態：**not-run**。本環境的 CUA 只提供 browser，沒有 native app 操作或觀察介面。已完成 Debug Rust 編譯及隔離 backend 的受控瀏覽器測試；兩者不能證明原生視窗生命週期。這是 G2 的缺项，不能改列 G5 而提早開 W2。

## 固定候選與隔離

- 工作樹：`D:/FH6-frontend-ia-20260913/shell`。執行前記錄 `git rev-parse HEAD` 及 `git status --short`；產品檔必須無未提交修改，測試期間所有作者停寫。
- 使用既有 `dev_full.bat`、`dev_lite.bat`，依序執行。两者共用 Vite 1420，不能同時啟動。
- Debug 預設 source sidecar 的資料目錄是 checkout 的 `backend/`。本次使用已存在的 `FH6_NO_SIDECAR=1` 與 `BACKEND_PORT` 契約，搭配外部 backend 的 `--data-dir`，將持久化限定在 scratch。
- Coordinator 先以自己的終端 handle 停止 browser candidate Vite 及本輪 backend，確認 TCP 1420/8001 與 UDP 8000 已釋放；不廣域終止其他程序。
- Backend 資料目錄為本輪明確指定的 scratch，不影響使用者一般資料。Debug WebView localStorage 未另行隔離；初次 guide 只按關閉，不按「已閱讀」或「略過」，不操作 WIP toggle。

在工作樹根目錄，第一個終端啟動 backend：

```powershell
uv run --offline --no-project --python D:\FH6-HorizonTuner\.venv\Scripts\python.exe python -u backend/main.py --dev --data-dir D:\FH6-frontend-ia-20260913\shell\scratch\g2-native-runtime
```

第二個終端使用相同工作樹：

```powershell
$env:FH6_NO_SIDECAR = '1'
$env:BACKEND_PORT = '8001'
.\dev_full.bat
# 完整關閉 Full 與該次 dev 程序後，再執行 Lite。
.\dev_lite.bat
Remove-Item Env:FH6_NO_SIDECAR, Env:BACKEND_PORT
```

保留外部 backend 供 Full/Lite 依序使用。它不屬於 Tauri owned sidecar，兩個 variant 結束後由啟動它的終端停止。這些命令沒有在本文件產出時執行。

## 必須由實際視窗觀察的項目

| 項目 | 操作與合格結果 |
| --- | --- |
| C5 Full 啟動 | 原生主視窗 `FH6-Horizon Tuner`，backend 已連線；四入口即時／調校／賽事紀錄／HUD。無 startup error。 |
| C5 Lite 啟動 | 原生主視窗 `FH6 HorizonTuner Lite`，backend 已連線；僅即時／HUD。 |
| C4/C5 入口 | Full/Lite 均可開 Data Out guide 與選單的設定／外觀／診斷／更新／關於；無遊戲時 Data Out 待確認是預期。 |
| H5 Full 與 Lite 各一次 | HUD 按啟動後，必須觀察到獨立 `Horizon Tuner HUD` 視窗；HUD → 即時 → HUD 時視窗保持存在，按鈕仍為關閉，無 action/persistence error；最後明確按關閉，視窗消失。只看到按鈕改字不算通過。 |
| C5 尚需追加 | dark/light/core modes 首幀、StrictMode 啟動、動態 port 的真實 readiness/導覽結果。上述 8001 程序只涵蓋指定外部 port，不能單獨宣稱完整動態 port 驗收。 |

HUD 在無遙測時可能透明；請以實際獨立視窗狀態判斷，不能以 Vite browser 代替。HUD launch/close 會刻意更新此隔離 backend 的 `hud_config.json`。本次不操作樣式、螢幕位置、音訊或重設。

## 回報格式與限制

每個 variant 分別記錄：完整 SHA、dirty 狀態、命令、隔離資料根、HTTP/UDP port、原生主視窗、HUD 開啟／離頁／重入／關閉結果、任何錯誤。C5 與 H5 分別填 pass/fail/not-run；未觀察的子項維持 not-run。

沒有真實 FH6 資料、MoTeC launch、release artifact 或三次效能比較；不據此宣稱 G5 通過。最終未完成項由 Coordinator 納回 acceptance matrix。
