## 已存在的介面與生命週期

| Owner | 真實 export / consumer | 邊界 |
| --- | --- | --- |
| Shell | `AppShell`、`WorkspaceRegistry`、`WorkspaceProps`，由 App/LiteApp 使用 | 只知道 workspace/surface/狹窄 SessionIntent，不知道 Tune step 或 Road 子頁。lazy registry 固定在 module scope，一次只掛載 active workspace。 |
| Full entry | `FullWorkspaceShell` → `prepareSession=applySessionIntent`、`Runtime=SessionsRuntime` | AppProviders 順序保留；HUD → Tune → Road → Sessions providers 在切頁區外，Toast 仍在 AppProviders 內。 |
| Lite entry | `commonWorkspaces` → Live/HUD | 不掛 Tune/Road/Sessions provider 或 SessionsRuntime。能力契約拒絕不允許的 intent。 |
| Tune | `TuneSessionProvider/useTuneSession` → `TuningWorkspace` 的正式／Developer consumer | 草稿、step、capture/measurement lifetime 與 pending saves 歸 Tune；complete/blocked/invalidated 強制更新 UI，普通影格仍節流。 |
| Road | `RoadValidationProvider/useRoadValidation` → `RoadWorkflowView` | 控制器保存 prepare/finish/candidate drafts、selection、operation ownership；page poll 隨頁清理，backend run 不由頁面卸載停止。 |
| Sessions | `SessionsStateProvider/useSessionsState` | `applySessionIntent(intent,isNavigationCurrent?): Promise<boolean>` 先驗 exact header 與非空 samples，再提交 selection/data。失敗留原頁並提供 Retry；較新導覽使舊請求失效。 |
| Race runtime | `SessionsRuntime` / `RaceStatusPoller` | authoritative status 有 identity 才開始；unknown 不視為完成；無重疊 poll/abort。Live 完成才自動開啟，其餘工作區提供保留的明確入口。 |
| HUD | `OverlayControlRuntimeProvider` → HUD page 與 units bridge | 初讀成功前不寫預設值；串行 patch、巢狀未知欄位保留、pending writes 延後 global channel release。原生視窗行為仍待實際驗證。 |
