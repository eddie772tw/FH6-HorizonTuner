# 賽事分析與路線錄製

常規賽事保留自動／手動錄製。計時賽及漫遊則先選擇或建立自訂路線，再按「武裝路線」；啟用時已在起點範圍內會等待離開後再次進入。按下開關後，下一次有效起點穿越才開始錄製，開關隨即解除。

起點與終點從目前車輛的有限 `PositionX/Y/Z` 捕捉，觸發半徑可調為 5–50 公尺。這是目前可用範圍，尚未完成跨車種、車速與遊戲場景的實車校準。路線以 UUID 關聯；匯入不相容文件、已存在 UUID 或同批重複 UUID 均整批拒絕，不覆寫既有路線。Session 保存當次座標、半徑、名稱及模式快照。

## 起停與完整區段

- **計時賽**：離開後再次穿越同一起點才閉合一圈，使用遙測時間計時；通過起點不會自動停止。手動停止會排除未閉合尾圈。沒有完整圈時，有效圈數與有效樣本數都是零，圈速為未知。
- **漫遊**：起點與終點必須各自有效，通過終點自動停止。遊戲自己的 `LapNumber` 不會把同一旅程拆成多圈；來源值保存在 `gameLapNumber`。手動停止或中途遙測缺口的旅程保持不完整。
- **高速穿越**：相鄰、同車且有效的座標點之間，以線段和球體相交判定；兩端都在球外仍能捕捉穿越。無前點、缺少座標／車輛識別、時間倒退、超過三秒的資料間隔不會補造穿越。
- **資料缺口**：損壞當圈保存在 `invalid_laps`，不給有效圈速；後續有效起點閉合後，新圈可重新取得完整資格。`trim_analysis.valid_lap_windows` 明確記錄可用時間區段，預設分析與匯出依此過濾。

錄製期間不能切換模式、重新武裝或解除路線。停止／儲存會保存 session 並刷新最後樣本、圈次與修剪結果。`IsRaceOn` 只保留為來源欄位，不參與賽事、Drag、Road 或 ICE／EV 觀測的收錄資格與停止判定；車輛識別、時間、動作和所需通道仍必須有效。

## 原始資料與匯出

修剪是衍生邊界，不刪除原始樣本。可分別切換原始資料顯示及原始匯出；沒有有效樣本時，預設匯出會報錯，必須明確選擇原始匯出。

CSV 匯入提供本地預覽與圈次分析，不建立已保存 session；此時匯出及本機 MoTeC 開啟停用，可在 MoTeC 使用原始 CSV 檔案。零起算來源圈號在匯入時統一轉為一起算，保留來源圈號；圈次只在觀察到起點及連續下一圈閉合證據時完整。來源官方 `LastLap` 與 CSV 時間估算分別標為 `game-lastlap`／`motec-estimate`，無法證明的圈速保持未知。

已錄製 session 可匯出 41 通道 CSV，並下載 XML 工作區範本。速度、溫度、壓力等按欄位映射轉換；`Boost` 的領域單位是 Pa，CSV／LD 的 psi 通道使用 `Pa / 6894.75729`，CSV 匯入則反向轉換。

原生 `.ld` 加 `.ldx` ZIP 匯出目前為**實驗性**。已有二進位結構、指標、通道、60 Hz 重取樣和 Beacon 時間窗口的本地測試，尚未在真實 MoTeC i2 安裝中完成開檔與通道核對。Gear／LapNumber 採前值保持，避免提前換檔／換圈。LDX 只將匯出窗口內完整圈用於圈數與最快圈，不把尾段或未知圈界變成 Beacon。

若有效圈之間存在資料空洞，預設 LD 匯出會拒絕跨洞插值；可選 CSV 保留原有時間區段，或明確匯出原始資料供檢查。以上本地驗證不代表真實遊戲高速穿越、所有車種或 MoTeC 實機相容性已通過。
