# Integra 無空力候選：同位置比較

2026-09-09。比較211420與212758兩場相同設定；202440軟前彈簧場作輔助對照。以172441第二圈實際軌跡為參考，每1公尺建立線段、每2公尺取共同座標，起終點各裁切20公尺。這不是導航理想線，也不以橫向偏差評分。原始資料、分析器及完整100公尺分段結果位於ignored scratch/a700-no-aero-spatial.py與a700-no-aero-spatial.json。

## 相對軟前彈簧場

211420相較202440在共同區段第二／第三圈只慢0.004576／0.002147秒，均小於一次約0.0167秒的取樣間隔，不能視為分出優劣。212758則慢0.014557／0.044713秒。

兩個候選的1820–1920公尺區段，在兩圈皆比202440慢約0.0155–0.0164秒，速度差約−1.32至−1.39 km/h、功率差約−17至−18 kW。這是值得追查的共同檔位／制動／出彎區段，不先歸因於彈簧；其他區段也存在相反收益。202440只是三場soft中的一場，尚非完整組間位置統計。

## 對公式研究的意義

目前991.4前彈簧與新齒比的整套候選，不足以證明優於660.9舊齒比。需將動力工作區及ANNA的換檔選擇列入配對條件，避免由整圈功率中位數推導底盤優劣。行程模型可以用991.4作不同設定下的外部檢查，但齒比與縱向加速度不同時不能視為嚴格相同負載，更不能拿這個中間剛度點直接擬合純彈簧性能曲線。
