# FWD 公路／環道懸吊：Integra A700 的下一輪試驗起點

2026-09-09。此文件是研究與可執行的測試計畫，沒有改動產品公式、遊戲設定或 runtime。本文件將 FH6 本機證據、FH5 社群經驗與實車工程原理分開：本機對照最直接地支持這一部 2023 Acura Integra A-Spec 在目前北部環道／ANNA 條件的表現；後兩者用來提出可檢驗的方向，不能替代 FH6 的同條件驗證。

## 下一輪的最小試驗序列

所有場次固定：同一 Integra 改裝、前空力 207 lbf／後空力仍不改、北部環道 3 圈、無對手與交通、春季晴朗固定早晨、相同輔助與 ANNA。每次只在賽前調校頁改一個顯示數值，拍下或記下讀回值；完成後用畫面完賽時間限定 telemetry 檔案。不要把第二場正在收集的軟彈簧結果預先混入決策。

### Gate 1：先把前彈簧方向重複完

唯一變量是前彈簧，其他保持 Forzab：

| 接續順序 | 前彈簧（lb/in） | 目的 |
|---|---:|---|
| S2（已封存） | 660.9 | 畫面與完整 telemetry 都與 S1 同方向；writer 已正常 exit、SHA256 已記錄，為可審計 replicate。 |
| H1 | 1254.4 | 恢復對照。 |
| S3 | 660.9 | 第三個 soft replicate。 |
| H2 | 1254.4 | 第三個 hard replicate。 |

既有的 `S1=660.9 → H0=1254.4 → S2=660.9` 加上 H1（正在賽事、尚無結果）、S3、H2，目標是讓兩組各達至少三場、且穿插順序。若任一場最終檔案不完整、或有介入／事故，標記無效並重新收一場，而不是補算。這個 47.3% 的前彈簧降幅很大，但正因前兩個 soft 場都顯示可辨識線索，現在不宜先改成更多中間值稀釋交替重複證據。

**Gate 1 的預先登錄判讀提示，不是硬否決規則：** 以 soft 組三場中位總時間約快 `0.10 s`、且組間範圍不完全重疊，作為「可進入下一項單變量」的較強信號；共同空間彎中／出彎速度不退步，且沒有新出現的持續近端點、碰撞或不可控失穩。`0.10 s` 是作者提出、相對既有約 0.03–0.04 s 組內範圍的保守操作性假設，不是統計顯著性、也不是自動接受或拒絕界線：小於 0.10 s 但跨場穩定、區段一致且代價低的收益仍應保留比較；反之，大於它但伴隨路線或行程代價也不通過。

**Gate 1 的暫停訊號：** 若效益與區段表現不一致，結論只應是「方向未確認」；比較 1254.4 與其他合理中間值的選擇仍由全部證據決定，不能自動退回 1254.4。若 soft 在可比路段的任一輪 `normalized travel ≤0.05` **或** `≥0.95` 比例約為 hard 組兩倍，且 SuspensionTravelMeters 反覆停在相同伸展端或壓縮端、並伴隨速度／滑移變差，暫停再往同方向改彈簧，先單獨審核車高／行程。兩倍比例也是作者提出的早期風險篩選假設，並非硬否決門檻，且不標稱離地或觸底。

### Gate 2：只測一個保守的後 ARB 增量

在 Gate 1 選出的前彈簧固定後，首先測試 **後 ARB 28.5 → 33.5**（+5.0、+17.5%）；前 ARB 保持 37.5，前後彈簧、阻尼、車高與前差速器保持不變。取得三場交替對照：基線、R+、基線、R+、基線、R+。若第一個 R+ 已造成明顯失穩，立即回到基線，無須測更硬。

只有在 R+ 三場有一致但未達明確收益、且沒有下列失敗訊號時，才做第二階 **33.5 → 38.5**（相對原始 +10.0、+35.1%），仍完整交替三場。它是辨識「小幅後剛度是否有益」的上限探索，**不是**前／後 ARB 反向調整或後 ARB 拉到 65 的背書。

後 ARB 的成功判讀以總時間中位約快 `0.10 s` **或**可重複地縮短預先選定彎中區段作較強訊號；也要檢查入彎／彎中前輪 CombinedSlip 或 ANG 高端不惡化、出彎速度不降，且沒有較多尾部突發 yaw／路線偏離。`0.10 s` 延用上述作者提出的操作性假設，較小但跨場穩定的收益不應因此自動否決。只看更高 yaw rate、較小 Roll 或較少後輪滑移都不是成功。

**後 ARB 暫停訊號：** 若 R+ 跨場變慢約 `0.10 s`、或同一彎段更低速度、更多後軸滑移／更大的 yaw-rate 尾端、ANNA 路線偏離／碰撞、或後輪更常卡近伸展／近壓縮端而沒有時間收益，優先回讀基線並停止往 38.5。這些是預先登錄的風險訊號，不是以單一場次自動裁決的硬門檻。它們直接限制「後 ARB 極硬一定更會轉」的社群主張：ARB 把同軸左右懸吊耦合，顛簸單輪事件與後軸負荷變化可使它變慢或不穩。

### Gate 3：若前彈簧與後 ARB 各自通過，再隔離後彈簧

僅在 Gate 1／2 找到可重複的配置後，測試後彈簧 **823.1 → 900.0 lb/in**（+76.9、+9.3%），其餘保持 Gate 2 贏家。三場交替基線／R-spring+。這個幅度遠小於前彈簧已觀察的 593.5 lb/in 變化，目的是辨別少量後軸 ride／roll stiffness 是否改善轉向，而不把「前軟後硬」變成一次同時改兩軸的敘事。

若後彈簧提高帶來跨場一致的後軸滑移、近伸展／近壓縮端行程、彎中速度或時間代價，撤回；若沒有約 `0.10 s` 或區段一致改善，也只表示證據不足，不因該操作性假設自動撤回。沒有 motion ratio 和輪荷時，不應預先設定更大的後彈簧階梯。

## 阻尼、行程與差速器：如何避免把交互作用誤判成彈簧結論

**阻尼不能跟著 Gate 1 同時改。** 1254.4→660.9 會改變有效固有頻率；實車工程上，阻尼配合應以輪率、簧上質量與 damper curve 為基礎，但 FH6 缺少這些量。因此 Gate 1–3 固定 11.8／9.2 rebound、7.1／5.5 bump，才可將結果歸因到各自唯一變量。

若 Gate 1 選 soft 前彈簧而成績改善、卻在煞車轉向出現慢收斂或前軸行程反覆接近一端，才開一個**阻尼專案**：先以同軸、同方向小步 **前 rebound 11.8 → 11.3** 或 **前 bump 7.1 → 6.7**（一次只選其一、三場交替），不是雙調。前者著重回彈／內側輪瞬態，後者著重壓縮／外側輪入彎瞬態；Racecar Engineering 的方向性支持它們可改變瞬態前軸輪荷，但不能保證 FH6 slider 相同。阻尼試驗的否決條件是更長的震盪／更高垂直 G 尾端、端點停留增加、入彎／出彎時間變慢或成績無改善。若沒有上述特定症狀，不試阻尼。

**行程與車高保留為保護欄。** 所有試驗維持 7.0／7.2 in。soft 前彈簧不是自動應降低車高，也不以較低 Roll 當目標。每一場報告各輪 NormalizedSuspensionTravel 的 P05/P50/P95、`≤0.05`／`≥0.95` 時間比例、SuspensionTravelMeters 範圍，及由 travel 對 race time 差分得到的非原生 travel-speed proxy，並切分煞車、穩態彎中、全油門出彎。出現任一端點 proxy 的變化時，先和同段速度及滑移一起判讀，再考慮單獨將受限軸車高加 0.2 in 的測試；不在彈簧／ARB 場次加車高。

**差速器是明確混雜因子，暫不混改。** FWD 的 40% acceleration／10% deceleration 同時影響兩個驅動前輪的轉速差。現有資料有前輪左右 RAT/ANG 差與制動／全油門滑移，但沒有輪速或輪荷，不能稱內輪空轉或斷言應提高／降低鎖定。先在固定的 Gate 贏家上，僅當「全油門出彎前輪左右 RAT/ANG 差和 CombinedSlip 尾端升高、速度卻下降」在多場一致時，才試 **acceleration 40→30%**；若改善速度而沒有更高滑移，再可比較 30→20%，每階三場交替。若是鬆油／煞車轉向問題，另以 **deceleration 10→5%** 作單變量；不與 acceleration、ARB 或彈簧並改。社群對「更鎖／更開能消除 FWD understeer」的方向本身矛盾，正是要用這個相位化條件而非成見決定。

## 最有辨識力的輸出與紀錄表

每個設定組只把「一場」當作一個 replicate；不要把上萬 telemetry 幀當成獨立樣本。總時間以畫面結果為主，資料檔以 race-time reset 與 finish 限定。每場先標記碰撞、ANNA 接管失敗、選單干預或天候／賽事不符；此類場次不補進主要中位數。

| 問題 | 主要指標（同圈、同座標區段） | 輔助指標 | 不可作的推論 |
|---|---|---|---|
| 是否真的更快 | 總時間、最佳圈、預先選定彎中和出彎的經過時間／速度 | 組中位、最小–最大、路線對齊誤差 | 不以單場最佳或全圈 P95 代替成績。 |
| 前軸是否較少飽和 | FL/FR 的 abs(ANG)、abs(RAT)、CombinedSlip P90/P95，按制動、穩態彎中、全油門出彎分段 | 前輪左右差、相同段側向 G 與速度 | 沒有輪荷、輪速，不稱接地面積、輪胎摩擦圓或內輪空轉。 |
| 後 ARB／後彈簧的代價 | RL/RR 同類滑移、yaw-rate 分布、出彎速度、路線偏離／碰撞 | Roll、橫向 G | Roll 變小不等於抓地變高；後溫度逐幀相等也不作左右胎溫診斷。 |

| 差速器交互 | 全油門出彎前輪左右 ANG/RAT/CombinedSlip 差，配同段速度／油門／功率 | 前軸滑移高端 | 不以左右差單獨診斷差速鎖定或扭矩分配。 |

## 當前建議與尚未知

最有效率的下一步不是更軟前、硬後或後 ARB 拉滿，而是先完成 660.9／1254.4 的交替三場證據。若它通過，後 ARB 先由 28.5 只升至 33.5；只有可重複收益且無失穩才到 38.5。這是有工程方向和 FH5 社群啟發、但不假裝已知 FH6 力學映射的起點。

尚未知的是：第二個 soft 場結果、後空力值、FH6 的彈簧／ARB／damper／diff slider 實際曲線、前後輪率與 motion ratio、輪荷／輪速，以及結果是否能跨賽道、控制器與車型重現。故本文既不支持修改共用公式，也不作 FH6 或任何 Forza 世代的通用 FWD meta 定論。
