# Integra A700：基準與 Forzab 六場綜合比較

日期：2026-09-09。分析對象為 2023 Acura Integra A-Spec、ordinal 3726、A700、FWD、半熱熔、373 hp、338 lb-ft、1321.316 kg、57% 前重。北部環道三圈、春季晴朗固定早晨、無對手及交通、ANNA 控制、ABS 開／TCS 關，其餘條件保持一致。基準私人調校為 `ht a700 base 0909`，候選為 `Forzab`；實際設定及逐頁核對紀錄見 [測試紀錄](integra-a700-test-checklist.md)。本分析未操作遊戲、未更改設定或產品公式。

**綜合判斷：Forzab 在這條路線與 ANNA 下有小幅、三場一致的整體速度收益，動力使用分布尤其改善；底盤表現則有取捨，不能稱為全面更穩或抓地全面提升。** 高速輸出及換檔後轉速較有利，後輪高端 normalized slip 降低；但起步首達速度較慢、前輪高端滑移及左右差增加，懸吊更靠近伸展端，車身 Roll 分布也未縮小。這一組適合保留為比較候選，尚不足以把整套公式定為已校準或將改進歸因於單一設定。

檔案均為 `scratch/integra-a700-northern-20260909-<尾碼>.jsonl`，內容是 `{receivedUnix, frame}` 的 decoded WebSocket 訊息，並非 UDP 原始位元組。每份只取首個車輛及 PI 符合、`IsRaceOn=1`、`0≤CurrentRaceTime<1` 的賽事開始；遇賽事時間倒退超過一秒便停止，且嚴格限制至已核對畫面 finish。檢查三圈存在、賽事時間遞增及車輛一致。排除起跑非穩態，以 `LapNumber=1/2` 分別代表第二／第三圈；第三圈只分析終點前已有資料。

每場是一個重複試驗單位。先在每場／每圈算 P10、P50、P90、P95，再對三場取中位數及最小～最大值。附表的 `中位數 [最小, 最大]` 是三場各自統計量的彙總，**不是信賴區間，也不是把上萬幀當獨立試驗**。各圈分開報告，不把同場兩圈當成兩個獨立 replicate。六場按先基準後候選進行，沒有交替或隨機順序，仍存在順序及未記錄環境狀態的混雜。

取樣間隔中位數約 0.01667 s，最大僅 0.01894 s，未看到賽事時間軸上的長缺口；資料比例以幀數表示，近似時間佔比，不是精密時間積分。`TimestampMS` 有 42–136 次相鄰重複，但 `CurrentRaceTime` 及其他內容仍前進，因此不以 TimestampMS 盲目去重。原始 UDP 遺失率無法從這些 decoded 資料完全重建。

目前重讀檔案，183255／183746 均為 11161 個有效幀；較早摘要各為 11159 幀。末幀至畫面 finish 的差目前為約 0.018／0.017 s，取代較早快照的約 0.051 s；任何版本都不能把末幀當作實際完賽時間。首圈 `CurrentRaceTime − LastLap` 的 offset 基準約 2.650 s、候選約 2.717 s，故三圈 LastLap 直接加總不等於畫面總時間，起步差也不能只解讀成輪胎或齒比效果。

單位依 [FH6 官方 Data Out 文件](https://support.forza.net/hc/en-us/articles/51744149102611-Forza-Horizon-6-Data-Out-Documentation)：ANG、RAT、CombinedSlip 為 normalized 值；本報告使用絕對值分布，未轉為角度或物理滑移率百分比。Yaw/Pitch/Roll 的 radians 才可換 degrees。AccelerationX/Y/Z 依既有車體軸解讀為側向／垂直／縱向，換 G 使用 9.81 m/s²；不是重力補償後的輪胎力。Power 為 kW，Torque 為 Nm，Position 與 SuspensionTravelMeters 為 m。NormalizedSuspensionTravel 的 0 是伸展端、1 是壓縮端。TireTemp 沿實测及既有 parser 的 °F 表示；官方該文件未指定溫度單位，不能寫成官方已確認。

完整欄位沒有 AngularVelocity、輪速或原始碰撞欄位。附表 yaw rate 是 unwrap 相鄰 Yaw 再除賽事時間差的**推導量**，不冒充原生角速度，也不等於相對路面／車身軸 yaw rate。Roll/Pitch 是車身姿態，含路面坡度、路線及側傾，不能把全部角度當懸吊變形。四輪順序為 FL、FR、RL、RR。

## 輪胎、制動與車身：並非所有分布一起改善

全圈前輪 ANG P95 上升：第二圈 FL 0.799→0.891、FR 0.913→0.960；第三圈同方向。前輪 CombinedSlip P95 也上升，第二圈 FL 0.953→0.975、FR 1.142→1.186。相反，後輪 ANG／CombinedSlip 高端大致降低，第二圈後右 CombinedSlip P95 0.782→0.716。後輪滑移尾端較低是有利線索，尚不足以證明最大抓地力更高。

左右分配沒有變得更一致：前輪 |RAT| 左右絕對差 P95 第二圈 0.573→0.629、第三圈 0.572→0.623；ANG 左右差 P95 0.185→0.218／0.173→0.203。差速器、定位、車身滾轉、輪胎負荷及 ANNA 路線都可能參與，沒有輪速與垂直輪荷便不能直接判定「內輪空轉」或由某個差速鎖定值造成。

分階段後，不能把全圈前輪增加一律歸為出彎問題。全油門彎中（相同油門條件、|側向G|≥0.6）第二圈前左 ANG P95 0.636→0.615、前右 0.694→0.690，CombinedSlip 尾端也略降；但前右 RAT P50 0.313→0.336。該phase速度 P50 147.407→147.063 km/h、P95則198.714→199.303，代表彎型混合與速度分布有取捨。全油門直線 normalized RAT 中位數微升，功率卻提高，不能把任何滑移增量都當性能損失。

制動相位以 BrakeInput>40 作描述性分段，不是 ABS 啟動辨識。其時間佔比第二圈 12.763→12.864%、第三圈12.507→12.721%；縱向加速度中位数約 -1.266→-1.265 G、-1.285→-1.261 G，沒有整體更強制動的證據。煞車期右前 CombinedSlip P95 1.527→1.584／1.443→1.547，ANG 尾端也升高，值得關注入彎負荷分配。相位含混合煞車轉向和引擎煞車，尚未做同速至停車的煞停距離測試，不能用負功率更大或全圈負加速度尾端推論煞停距離縮短。

第二圈 |側向G| P50 1.066→1.069、P95 2.008→2.009，第三圈亦相近；這不支持「極限側向抓地大幅提升」。Roll P10/P95 從 -3.188/+3.475° 到 -3.321/+3.695°，第三圈相同方向，不能稱側傾更小。垂直G P95 0.375→0.382／0.380→0.385，姿態 Pitch 分布接近。推導 |yaw rate| P95 0.638→0.650／0.645→0.650 rad/s，中位數也略高、P90略低；轉向輸入 P90 14→15。這些描述顯示車輛／控制需求有細小改變，既不能以數值較大稱更靈活，也不能以數值較小稱更穩。

## 懸吊與胎溫：壓縮餘量增加，伸展端餘量減少

候選前彈簧 660.9→1254.4 lb/in、後609.6→823.1，車高也提高0.2 in，其他阻尼／ARB同時變動。第二圈 normalized travel P50，FL 0.421→0.249、FR 0.393→0.231、RL 0.406→0.306、RR 0.380→0.287；P95皆下降。前左 meters P10/P95 -0.010/+0.028→-0.006/+0.017 m，實際行程擺幅縮小，不能只用 normalized 尺度變化解釋全部差異。

任何一輪 normalized≤0.05 的幀佔比，第二圈0.083→1.774%、第三圈0.055→1.852%；任何一輪≥0.95皆0%。0.05／0.95僅為本報告近端點分箱，不是 FH6 官方離地或觸底判定。觀測支持壓縮端餘量增多、伸展端附近時間增加，**不支持原基準常觸底，也不證明候選已離地**。對更顛簸路面的適應性尚未知；以更硬彈簧直接等同更好是過度結論。

第二圈胎溫 P50：FL 167.077→165.927°F、FR166.818→167.190°F，第三圈168.540→167.319°F／168.701→169.049°F。左前略降、右前略升，前軸左右不對称增加，並不是四輪一致冷卻。後輪P50第二圈約131.433→131.344°F、第三圈132.862→132.947°F，差異很小，且第三圈較第二圈更熱，仍有熱態演變。

**所有六場的 RL/RR 胎溫在 decoded 幀中逐幀完全相等。** 目前 parser 是分別讀四個值，沒有在該欄位主動複製後輪；但沒有原始UDP交叉核對，不能把 decoded 的相等當作兩後輪物理溫度完全相同的證據，也無法做後輪左右溫差診斷。没有內／中／外溫度與動態胎壓，不能藉這組數據評定胎壓最適或外傾角已校準；較低溫也不自動較好。

## 位置對齊、判斷限度與下一個實驗

以基準第一場第二圈每約5秒一個三維位置錨點分成12段，其他場只在相應圈及參考經過時間±3秒找最近點，避免起終點重合誤配。全部配對維持前進順序，第二／第三圈所有錨點最大空間誤差為0.511 m。這代表可以做同一附近路段比較，不能證明每段整條路線或入彎姿態完全一致。12段時間差多是±0.017 s，接近一幀，甚至比位置差所對應的通過時間小，故不把單段勝負寫成確定收益來源。

第二圈候選在多數路段中位速度略高；S5兩圈都略低，S10時間差也小幅落後但速度中位數未必較低，呈現中位速度與通過時間並非可互換。附表列每段差；使用每場的時間後再彙總，各段中位差相加也不必精確等於總圈速差。主結論應以完整圈與三場可重複性為重，而非這些接近量化解析度的局部差。

| 綜合面向 | 本批判斷 |
|---|---|
| 整體賽事效率 | 小幅較好：完整成績、第二／第三圈速度與輸出分布一致支持 |
| 動力輸出分布 | 較好：高功率使用時間及高速帶輸出增多、換檔後RPM較高，峰值近似 |
| 起步與極低速非穩態 | 首達速度較慢；計時offset／控制混雜使純牽引因果未知 |
| 前軸滑移與左右分配 | 全圈高端及制動期較不利；全油門彎中部分尾端反而降低，需分phase |
| 後軸滑移尾端 | 較低；不足以證明更大抓地極限或更安全 |
| 懸吊行程與車身穩定 | 取捨：壓縮餘量增加，伸展附近時間增加；Roll未縮小 |
| 制動、胎溫最適化、人類操控及泛化 | 尚未證明改善；缺特定測試與必要欄位 |

**下一個最有價值的單變量測試：保留 Forzab 的齒比、後軸、差速、胎壓及定位，只將前彈簧從1254.4恢復到已核對的660.9 lb/in。** 這是利用既有可達設定作單軸回復實驗，沒有另造最適數值。其目的在於查明這次最明顯的前軸剛性變更，是否與較多伸展端事件及前輪尾端滑移的取捨相關，並觀察能否保留動力收益。這個兩點實驗只回答前彈簧在其餘候選組合下的條件效果，不能直接推出最佳彈簧或外推到基準整套。

採 Forzab／單變量回復交替或ABBA順序、各至少三場，重設相同賽事與可控制胎溫初始條件，事前固定判讀第二／第三圈、完整成績、前輪ANG/RAT/CombinedSlip各phase、伸展近端比例及同一空間錨點。若有時間收益但滑移／行程代價，要保留兩者；不以單一尾端數字自動決定採用。若先要回答「多少速度收益來自齒比」，可另做僅更換齒比組的受控實驗，但不要與前彈簧測試同時改。
