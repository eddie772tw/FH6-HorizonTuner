# MX-5 可辨識性核算與後軸試點規則

本分析在 A1→A2→F−1→A3 四場封存後、任何後軸試點前完成。來源與圈速判定見[首個試點](mx5-rwd-local-probe-20260910.md)。本文件不更改已預先指定的夾心比較，也不把新的全資料回歸取代原主要結果。

## 用真實設計矩陣核算

四場每場一個實驗單位，前軸 eF 為 [0,0,−0.050330033,0]，後軸全部零。以封存第2～7圈平均作反應，重新核對全部原始SHA後計算：

| 模型矩陣 | 欄數 | 秩 | 可識別結論 |
| --- | ---: | ---: | --- |
| 1、eF、eR | 3 | 2 | 後軸斜率未知 |
| 1、eF、eF² | 3 | 2 | 無法獨立估曲率 |
| 1、eF、場次順序 | 3 | 3 | 代數可解，但要求未驗證的線性漂移假設，僅剩1個殘差自由度 |

因 eF 只取 0 與 h，觀測點上 eF²＝h·eF，二次項和一次項精確共線。對任何在這兩個值不同的轉換 g，也有 g(eF)＝g(0)+[g(h)−g(0)]eF/h。因此含截距的兩參數回歸在這兩個設定上的欄空間相同；更換剛度座標不會增加資訊。

實際比較 eF、1/(1+eF)−1、sqrt(1+eF)−1 三種座標的OLS：預測最大差 **3.55×10⁻¹⁴ s**，殘差平方和均約 **3.914064965×10⁻⁵ s²**。這是有限設計上的代數等價，不能宣稱整段曲線相同、真實物理收斂或三個模型都經過性能驗證。F−1只有一次，其殘差近零是兩水準模型直接擬合該點的結果，不是精準預測的留出證據。

全資料OLS前軸斜率−0.299355 s/相對剛度，与預先夾心比较的−0.338494不同，因前者合併A1/A2/A3成均值，後者只用相鄰A2/A3。此差別不是物理方向翻轉；正式試點結論仍依原規則。

重複同一設定可改善對變異的了解，但不能補上零欄或分辨曲率。新增獨立後軸設定使三個非共線點的 [1,eF,eR] 秩達3；這僅是最低代數可辨識條件，仍須獨立重複、聯合候選留出與跨車驗證。故下一場取後軸資訊，比再以MX-5現有兩個前軸水準排名曲線更有價值。

核算腳本 `scratch/audit-mx5-identifiability.py`，結果 `scratch/mx5-identifiability-audit.json`；來源四場摘要SHA `06bdbf922405944464fac9b827b5a60595fd432d861af32633cf16105367482e`。斷言檢查兩種秩不足與三座標預測相同；數值檢查不是性能測試。

## 下一區塊預先規則：獨立後軸

下一區塊為 **A4→R−1→A5**，重新開始前先核對車輛、賽事與完整固定設定，A4提供本次恢復操作的即時基準。僅R−1後彈簧目標645.1×0.95＝**612.845 lb/in**；前彈簧606.0固定。必須現場確認後軸合法刻度，以最接近目標的可達值讀回；後軸刻度尚未確認，不由前軸0.5刻度推定。回歸用實際 eR，未讀回之前不記為已套用。

同樣5%是首次局部辨識幅度，不是RWD通用倍率或最優方向。選軟化使前後兩軸在相同相對尺度上可比較，並補上獨立軸資訊，不是由驅動形式預先判定軟化會改善牽引。後軸回彈／壓縮11.8／7.4固定，ARB39.00／30.60、車高4.7／4.4與其他基準保持；胎壓、定位、變速箱、空力、差速器與煞車固定。

沿用北部環道七圈、同一ANNA與環境；全封包與七圈保留，每場為實驗單位。主結果2～7圈均值，敏感度3～6與2～6，首圈與總時間另列。R−1比較mean(A4,A5)，另列相對兩場各自差值。沒有可比的A4或缺少末圈回報時不估效果，不以舊A3偷偷替代當前區塊基準。

沿用事先實用改善門檻 **0.05 s/飛行圈**，未達則恢復基準、停止本輪該軸細調；超過且兩側基準和窗口均支持，仍須獨立重複才考慮採納。保留漂移、路線、溫度、控制輸入、滑移與行程端點等完整動態證據。候選出現新反覆長端點事件、失控、擷取缺口或人為干預先判明，不憑圈速單獨通過。沒有將此操作門檻當作統計等效界限。

本區塊完成後才計算探索性βR，並檢查前後軸差值是否大於區塊基準漂移。若兩軸都沒有實用收益，保留這輛車的基準，優先擴大車輛／場景覆蓋；不為了得到改善而反覆擴幅、改門檻或增加模型階數。任何聯合設定是新的留出驗證，不能由單軸代數可解性直接宣布成功。

撰寫時狀態：本文件是已封存的數學核算與下一區塊預先規則，當時A4、R−1、A5尚未執行。後續實際進度見[後軸區塊](mx5-rwd-rear-block-20260910.md)。

使用者後續於R−1開始前授權：當5%不足以辨識時提升到10%。因此上文5%無收益即停止的後續行動，由[自適應幅度規則](mx5-adaptive-step-heuristics-20260910.md)取代；原分析窗口、完整對照與0.05 s/圈改善門檻不變，不改寫既有結果。
