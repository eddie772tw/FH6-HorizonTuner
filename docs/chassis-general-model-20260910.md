# 跨 FWD／RWD／AWD 的底盤主要模型

## 現行決策更新：頻率初始解優先

2026-09-10 MX-5 A6→S1→SD1→A7 完成後，以使用者後續指定的頻率彈簧與分驅動阻尼模型作主要初始解。下文局部斜率／正則化方案保留為歷史研究與出現明確退步時的診斷工具，不再要求每輛車先完成多點尋優；「第一版保留基準阻尼」「不增加三組固定倍率」是較早決策，已由本節取代。驗收以方向合理、近似可用且無明顯退步為主，不把缺乏顯著差異當作統計等效。

令總質量 W 為 kg、前重比例 p、簧上比例 s 暫取0.9、前頻率 f、後前頻率比 r，且 q 定義為彈簧位移／輪端位移：

    m_f = W*p*s/2; m_r = W*(1-p)*s/2
    K_f = m_f*f²/(248.405346*q_f²)
    K_r = m_r*(r*f)²/(248.405346*q_r²)  [kgf/mm]
    K_r/K_f = ((1-p)/p)*r²*(q_f/q_r)²

使用者248的簡化常數亦可，與上式差約0.163%；採哪一種須固定並記錄，最後依遊戲合法刻度取整。f一般先取2.0 Hz；有可信輪胎分類才用1.9／2.1 Hz。分驅動參數如下，屬待跨車驗證的先驗：

|驅動|r|前回彈|後回彈|前壓縮|後壓縮|
|---|---:|---:|---:|---:|---:|
|FWD|1.15|b|1.15b|0.6b|0.75b|
|RWD FR|1.00|b|0.85b|0.6b|0.48b|
|AWD|1.05|b|0.95b|0.6b|0.57b|

b初始14.0。後軸壓縮保留使用者指定倍率，不能另強制全車C/R=0.6。滑桿不等於物理阻尼比，且未知q時不能由懸吊類型猜定後稱為精確實測頻率；應先報輪端目標及尚缺的幾何假設。ARB、車高及其他固定項維持各車凍結基準。詳細推導、來源及MX-5有限支持見[頻率與阻尼驗證](mx5-frequency-damping-validation-20260910.md)。

## 決策與適用範圍

採用「各車凍結基準＋無量綱剛度修正＋局部線性反應＋最小改動限制」。FWD、RWD、AWD 共用相同方程。共用結構不等於共用斜率，更不等於把 Integra 的 528.4 lb/in 或 0.7995 倍率套到所有車。

目前只針對既定 Road／Circuit 場景。更換車、升級零件、輪胎、路面、賽道或代駕方式均可能改變有效範圍。不能由本分析延伸宣稱適用甩尾、越野或直線加速。

既有證據與模型比較見[簡化決策](chassis-formula-parsimony-20260910.md)及[八場交叉試驗](chassis-spring-damping-block-20260910.md)。前彈簧線性模型在原試驗範圍表現較好；平方根阻尼聯動未呈現一致額外收益。因此第一版保留基準阻尼，優先識別彈簧反應。

## 1. 真正能跨車共用的物理关系

令 i 為前／後軸的一個車輪，m_si 為該角簧上質量，r_i 明確定義為「彈簧位移／車輪位移」。小位移、固定幾何且忽略輪胎柔度的單自由度近似：

    k_wi = k_si r_i²
    f_i = sqrt(k_wi / m_si) / (2π)
    k_si = (2π f_i)² m_si / r_i²

k_s、k_w 使用 N/m，m_s 使用 kg。這是自然頻率關係，不是最佳圈速定理。OptimumG 採倒數的 MR＝車輪／彈簧位移，所以其寫法為 k_s＝(2πf)²m_s MR²；兩者一致。[原始工程說明](https://optimumg.com/wp-content/uploads/2020/01/SpringsDampers_Tech_Tip_2.pdf)

同車、相同零件及幾何附近，可消去難以取得的 m_s 與 r：

    k_si / k_si0 = (f_i / f_i0)²

因此相對剛度是合理的可觀測控制座標。但跨車不能消去不同車的質量和運動比：

    k_s,new / k_s,ref = (m_s,new / m_s,ref)
                         × (f_new / f_ref)² × (r_ref / r_new)²

這說明只用整車重量比例或驅動形式倍率移植絕對彈簧值會漏項。靜態前後重量比例也未必等於簧上質量比例。

目前實驗程式 `frontend/src/domain/tuning/chassis/suspensionSolver.ts` 使用簧上比例 0.86、MR＝1、預設 2.2／2.3 Hz，以及獨立的阻尼滑桿啟發式。這些是先驗假設，不能當作已識別物理量。記憶所述其他分支的 developerSolver.ts 不存在於本工作樹，本文以本地實際檔案為準。

**輸入不足時的主路徑：**直接讀回各車、各升級配置的基準彈簧，不要求使用者猜運動比、簧上比例或理想 Hz。若基準也沒有，先取得讀回值；只有滑桿範圍不能唯一決定性能最佳設定。物理頻率模型保留為資料齊全時的可選分析，不用默認常數製造精確感。

## 2. 採納的主方程

凍結該車參考值 k_F0、k_R0，定義：

    e_F = k_F / k_F0 − 1
    e_R = k_R / k_R0 − 1
    k_F = Q_F[k_F0 (1 + e_F)]
    k_R = Q_R[k_R0 (1 + e_R)]

Q 是已確認可調範圍內的合法遊戲刻度取整。先限制 e 的可行域，再取整一次；保留讀回實際值，回歸用實際 e。固定／未知範圍的項目不產生變更指令。e＝0 就是基準；由 lb/in 改顯示 kgf/mm 不改變 e。

需要總體與平衡的操作語意時，作等價線性換元：

    s = (e_F + e_R)/2,  b = (e_F − e_R)/2
    e_F = s+b,          e_R = s−b

s 是兩軸相對變化的平均，b 是相對前後差；它們不是實際總輪率或側傾剛度分配。第一輪識別仍使用單軸 e，避免換元後誤以為舊資料已覆蓋兩個方向。

性能反應採：

    y = (T − T_ref)/T_ref
    y_hat = α + β_F e_F + β_R e_R

T 的窗口先固定；主比較可用完整可比的第 2～7 圈平均，保留第一圈及全場時間作獨立結果，3～6、2～6 圈作敏感度檢查。若第七圈缺乏可靠終點資料，明確記為缺測，不偷偷改窗口。這是未來預註冊建議，不回改既有模型的訓練目標與留出結果。

α 容納參考場次和後續基準的差異；時間正規化有利跨車比較尺度，不會自動移除賽道、交通、ANNA 路線或溫度差異。

**目前資料只能支持固定後軸下的前軸斜率。**僅改前彈簧時 e_R＝0，無法估計 β_R；在 s,b 座標下 s＝b，同樣不滿秩。不得把未知 β_R 設為零再稱後軸沒有作用。新車尚無斜率時輸出基準與待識別狀態，不輸出偽最優解。

## 3. 「最小變動」如何變成明確數學條件

若斜率已能識別，在固定基準附近選候選 e：

    minimize  α + βᵀe + (λ/2) ||e||²
    subject to e in C,  λ > 0

C 為事先指定的局部盒狀區間，包含零、滿足遊戲上下限；尚未識別的軸固定為零。第一項估計性能，第二項懲罰相對基準的改動。λ 是保守程度，不是物理常數；不得用同一批結果反覆挑 λ 後宣稱泛化。另以行程異常、失控、配對品質等驗證門檻拒絕不合格候選，沒有可靠預測模型時不把它們硬寫成假約束。

連續盒狀問題有直接解：

    e* = projection_C(−β/λ)

因 Hessian＝λI 正定，有唯一連續解，不必搜尋高階曲線頂點。固定 λ 與 C 時：

    ||e*(β1) − e*(β2)|| <= ||β1 − β2|| / λ

這是候選對斜率估計誤差的穩定性界限。合法離散刻度上選最近可行刻度，平手先選改動較小者再以固定順序決定。取整可能造成一刻度跳變，因此連續界限不直接等於遊戲輸出的連續性。

這項正則化**不證明真正圈速存在該最小值**，也不保證實測回饋迭代收斂。它只提供穩定、可控的候選生成器。C 與 λ 尚沒有跨車校準值，當前不給所有車統一 ±10%／±20% 的常數。新增測點即使只是小幅改動，仍可能是未驗證區域。

若兩個候選的實際差異小於事先定義的有用改善門檻，且無一致動態收益，採變更較少者；資料不足則維持基準。不能把「沒有顯著差異」寫成已證明等效。未來用保留車輛的驗證比較 λ 和更複雜模型，而非反覆利用同一車的圈數。

## 4. 驅動形式與其他底盤項目

FWD／RWD／AWD 不改變上述垂直彈簧方程。它們會改變驅動力作用的車軸與彎道各階段的需求，因此可能改變 β，而非必然要求另一套彈簧算式。AWD 中央扭矩比例不能替代前後重量比例。

| 項目 | 主模型政策 | 何時增加自由度 |
|---|---|---|
| 彈簧 | 共用相對剛度方程；先估單軸、再估另一軸 | 後軸有獨立資料後才用雙軸模型；聯合留出不符才考慮交互項 |
| 回彈／壓縮阻尼 | 各車基準固定，避免自動平方根聯動 | 彈簧方案固定後另做有重複的阻尼區塊 |
| 防傾桿 | 各車基準固定；不以 AWD 標籤自動給極端前軟後硬 | 有明確彎中／出彎問題才獨立辨識平衡調整 |
| 車高 | 保留基準並監測行程、接地與碰底的可觀測代理 | 有一致異常才獨立處理，變更後重建局部基準 |
| 胎壓、定位、變速箱 | 按使用者範圍固定 | 不納入本轮模型 |
| 空力、差速器、煞車 | 延續試驗控制固定 | 不把相關舊稽核建議當作本輪調整授權 |

防傾桿的工程目標是總側傾剛度及其前後分配；彈簧本身也貢獻側傾剛度。因此遊戲 ARB 滑桿比例不能直接當成實際剛度比例，固定 ARB 也不代表改彈簧後總側傾平衡不變。[OptimumG Bar Talk](https://optimumg.com/bar-talk/)

有足夠多車資料後，才比較共享斜率、車輛偏差與驅動形式修正。只有一輛 FWD、一輛 RWD、一輛 AWD 時，車款與驅動形式混淆，不能辨別是驅動形式規律還是個別車特性。第一版不增加三組固定倍率。

## 5. 未來實測如何驗證泛用性（本輪不執行）

1. 每車讀回相同升級配置的原始基準與可調範圍；凍結設定、賽事和 ANNA 條件。各車基準不必等於現行公式輸出，兩者來源分開。
2. 基準與單軸候選分區塊重複，安排基準回訪和可行的隨機化順序。從小的合法步幅探索；不是把 Integra 20% 軟化當作起跑指令。
3. 必須包含獨立前軸和後軸變化才能識別兩個斜率。三個非共線設定只提供三參數代數可解性，不提供可信殘差或重複性；另留獨立重複和候選驗證場次。
4. 全部封包、第一圈、各飛行圈、終點來源與異常均保留。每場賽事是重複單位，不能把 60 Hz 封包或不同圈當成大量獨立實驗。
5. 先驗證「同一結構是否只需換各車基準與局部斜率」；跨車訓練後保留整車／整場景驗證。若只需這些替換，就沒有理由新增 drivetrain 分支。若聯合彈簧預測失敗，先檢查範圍與資料品質，再判斷是否真的需要交互項。
6. 事先指定有用改善門檻與動態退步門檻。差異沒有實用價值時採較少改动與較少參數的方案；結論保留「未分出」的可能。
