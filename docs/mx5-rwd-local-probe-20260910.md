# MX-5 RWD 局部彈簧辨識預先規則

2026-09-10，在 A2 基準進行中、尚未執行任何變更設定的 MX-5 賽事時制定。基準與已完成 A1 詳見 [讀回記錄](mx5-rwd-baseline-20260910.md)。

使用已採納的各車相對剛度模型，不移植 Integra 的最佳候選幅度，也不為 RWD 增加固定倍率。先辨識前軸，後軸斜率保持未知；此階段不是雙軸最優化。

## 第一區塊

順序 A1 → A2 → F−1 → A3。A1、A2、A3 全部原設定；F−1 僅前彈簧以 kF0 × 0.95 為目標，即 606.0 × 0.95＝575.7 lb/in，實際值以遊戲合法刻度讀回為準，eF＝讀回值/606.0−1。後彈簧 645.1 lb/in 不變；ARB、回彈、壓縮、車高以及其餘設定全固定。若不能可靠設定並讀回，保留基準，不猜刻度。

5% 是這輛車首次局部辨識的操作步幅，不是已驗證信賴域、通用調校係數或最佳值。同車固定幾何條件下對應頻率比 sqrt(0.95)≈0.97468，但未知運動比與滑桿映射不因此得到校準。這一步是取得斜率資訊的試點，尚不是正則化最优解。

主結果為每場完整第 2～7 圈平均；敏感度窗口第 3～6、第 2～6 圈，第一圈與官方總時間另列。所有遙測保留；每場一個實驗單位。

第一次 F−1 與相鄰 A2、A3 基準均值比較，另列兩個單獨差值；此順序非隨機化，夾心基準只減少簡單漂移的疑慮，不消除所有順序效應。單次候選只能提供探索性有限差分，不能證明效果可重複。

## 經濟性與品質規則

事先採 **0.05 s/飛行圈** 為本地探索的實用改善篩選門檻（約基準 60.193 s 的 0.083%）。這是減少無益迭代的操作選擇，不是遊戲物理常數或統計等效界限。

- 若改善未達 0.05 s，或與基準回訪差異同量級、不同窗口方向不一致，先維持基準，不為微小差異追高階曲線或更細刻度；結論是此步幅尚未分出有用收益，不是證明等效。
- 若改善超過門檻且兩個相鄰基準對比均支持、各窗口不矛盾，再以獨立候選重複與基準回訪確認，單場不晉升為採納設定。
- 擷取缺口、缺少第七圈完成資料、身份／設定不符或人工干預都保留並標記。存在未解品質問題時不估效果。
- 保留全場與逐圈輸入、溫度、滑移、行程及位置對照。候選出現基準沒有的反覆長行程端點事件或明顯路線偏離時先檢查資料和動態，不把更快圈速單独當作通過。端點代理不等於接觸力證據。
- 若前軸步幅沒有可用收益，停止前軸微調；未來需独立後軸變化才能估 βR。不得把 βR 未知解釋為後軸無效，也不得由一輛 RWD 歸納所有 RWD。

本規則不修改正式應用程式公式。前軸斜率只能在本車、本場景與此局部範圍解釋。

此結果支持維持簡單的各車相對剛度模型與小幅局部驗證流程，沒有支持新增 RWD 固定倍率，也没有證明 FWD 的候選幅度能跨車直接移植。下一個有辨識價值的方向是獨立後軸試點及基準回訪，避免繼續從同一前軸小差異擬合更多公式；本區塊未執行後軸變更。正式產品公式未修改。
