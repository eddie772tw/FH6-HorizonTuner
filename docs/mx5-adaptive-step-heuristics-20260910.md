# MX-5 自適應探測幅度與經驗法則

後續優先序更新：使用者提供頻率彈簧與分驅動阻尼模型，要求以驗證其優於預設值為主要目標。尚未執行的10%探測暫由[新公式實測計畫](mx5-frequency-damping-validation-20260910.md)取代；此處保留原自適應原則供後續辨識使用，不能視為已執行10%測試。

使用者於後軸R−1開始前補充：5%不足以產生足以判斷的差異時，提升至10%，並指派子代理尋找經驗法則。本規則覆蓋先前「5%無收益即停止該軸」的後續行動，不改寫已封存結果或0.05 s/飛行圈的實用改善門檻。

## 已指定的序列

先完成A4→後−5% R−1→A5。R−1實際讀回後612.6 lb/in、前606.0，後軸相對原值645.1為−5.037979%；車高4.7／4.4、阻尼及其他參數固定。已確認套用並開始擷取 `scratch/mx5-a700-northern-20260910-100724.jsonl`，結果待完賽。

5%效應若絕對值低於0.05 s/圈，或與相鄰基準漂移相當、窗口方向不一致，且没有新增明顯失控／端點等惡化訊號，採一次同軸同方向10%辨識擴張。10%從原始基準計算，不從5%候選再乘0.9：前545.4、後580.59 lb/in，均需讀回合法值。沒有收益不等於無效應；若已明顯惡化，則不因沒有收益而盲目加大同方向。

候選與前後基準成區塊比較，主窗口2～7、敏感度3～6／2～6、首圈與全場分列；每場是實驗單位，不把各圈當獨立重複。10%仍弱或不一致則停止該方向擴幅，轉向症狀對應的參數或跨車；10%有清楚改善則先獨立重複，再考慮較小步幅。前−5%已約慢0.017 s/圈，前−10%可作辨識試验，但不預測會更快。

## 子代理研究：工程先驗的適用邊界

子代理chassis_heuristics已查找一手工程來源與遊戲作者指南，沒有找到官方支持FH6固定10%為最佳幅度的證據。10%是使用者指定的試验步幅。

| 症狀 | 縮小試驗範圍 | 限制 |
| --- | --- | --- |
| 平順彎中持續推頭、行程正常 | 前ARB軟化或後ARB硬化，每次只選一軸 | 反應遲鈍與過敏需區分；尚非FH6已驗證方向 |
| 平順彎中甩尾 | 優先試後ARB軟化 | 出彎大油門打滑可能涉及扭矩／差速器，不能全部歸因底盤 |
| 顛簸抓地中斷且仍有行程餘裕 | 試受影響軸軟彈簧 | 軟化若增加端點或俯仰並變慢，停止該方向 |
| 行程端點伴隨姿態突變或速度損失 | 先確認端點語意，再評估硬彈簧或車高 | 本輪固定車高；normalized travel不是直接接地力 |
| 問題只在煞車／轉向／油門切換 | 單軸單項阻尼 | 過強壓縮可能減少順應，過強回彈可能在連續顛簸積累壓縮 |

上述承載／行程用彈簧、彎中平衡用ARB的分工及方向先驗來自[OptimumG Bar Talk](https://optimumg.com/bar-talk/)。阻尼反例見[Penske Adjustable Manual](https://www.penskeshocks.com/hubfs/Resources/Manuals/Adjustable-Manual1.pdf)，PDF第17頁。這些用於選下一個實驗，不能替代本遊戲實測。

在線性單自由度、質量／運動比不變假設下，fn∝sqrt(k)：−5%剛度對應−2.53%頻率，−10%對應−5.13%。固定阻尼係數時ζ∝1/sqrt(k)，−10%剛度使阻尼比增加約5.41%。因此本輪量到固定阻尼下的彈簧總效果，不能稱純頻率效果；不為維持理論ζ而同步調阻尼。遊戲滑桿是否具有這些校準量綱仍未證實。
