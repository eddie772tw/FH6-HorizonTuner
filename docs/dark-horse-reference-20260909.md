## 後續差異評估

模擬面板判讀修訂：使用者確認同一調校每次模擬都有可能出現誤差。下述現車／存檔模擬數字僅保存觀測，不能單憑差異確認 tune 不同；仍須比對實際零件及各頁調校值。相同模擬數字也不能證明配置相同。

### 調校存檔入口實機核對

2026-09-09：車庫 → 車輛 → 升級套件與調校 → 自訂調校；按 Backspace 開啟「設定管理」，可見載入設定、儲存設定、重設調校設定為預設值。載入設定預設進入「熱門」，不能從最左頁向左循環；持續點右分頁箭頭可到最右側「我的調校」。本次僅瀏覽，未載入或重設任何存檔。

「我的調校」出現三筆 S1 800 卡片；其中 `Touge&Street Best S1 Build`（2026/06/19）預覽為 841 hp、686 ft·lb、3839 lb，與現車不同。`Touge & Street Best Build V2`（2026/08/16）為 832 hp、640 ft·lb、3864 lb，但預覽空力效率 0.680、空力平衡 0.39、機械平衡 0.46、極速 182.7 mph，仍不同於現車 0.738/0.50/0.52/194.3 mph。V2 的三個平衡/效率數字與目前 Tuner 舊 profile 相同，是舊資料来源的線索，不能據此宣稱整份 profile 同源或已核對。存檔名稱、PI 與峰值規格不足以確認同一 tune。

本次再讀現車模擬面板為 0–100 mph 5.383 s、60/100 mph 制動 71.7/161.8 ft，與較早抄錄有小幅差異；未手動改滑桿，不將模擬結果變動當作性能改善或固定實測基準。

### 2026-09-09 公式一致性研究更新

本輪前段 MCP 已確認同車 ordinal 3847、EngineMaxRpm 約 9499.995；這是遊戲回報轉速上限，不是已完成的 WOT sweep。此次 API 重讀確認車重、配重、AWD、832 hp、640 ft·lb 與七檔已保存；profile 中 7500/4750 峰值 RPM、Stock 胎種、彈簧範圍及空力欄位仍有舊值，不能整份 profile 直接視為已核對輸入。

上述是無滑移、剛性傳動與名義胎徑的運動學結果，396.7 km/h 不是可達極速。原車檔距逐漸縮小；是否適合 ANNA 的換檔行為仍需實測。

**已修正的公式問題**：Road/Rally 最後整理檔比時，原本強制 `G_next/G_current <= (peakPowerRpm+50)/redline`。這等同要求紅線升檔後不得高於峰值功率轉速，卻沒有功率曲線支持；逐檔縮小齒比也會破壞前段求得的頂檔速度。已移除此 RPM 上界，保留遞減與 legacy 頂檔間距防護。最佳換檔須比較相同車速下兩檔的輪上牽引力；單一峰值轉速不足以決定。

|---:|---:|---:|---:|---:|
| 6500 | 0.738 | 3.43 | 0.40 | 0.67 |
| 7500 | 0.738 | 3.96 | 0.61 | 0.67 |
| 8500 | 0.738 | 4.49 | 0.67 | 0.67 |

這只驗證 solver 自己的速度目標不被後處理破壞，未證明該速度 prior 正確；37、0.95、0.12、起步速度及齒比間距仍未校準。測試增加三種峰值情境下的速度一致性（誤差小於 1%，只容許量化誤差）。
