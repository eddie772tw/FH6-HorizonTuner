Forza Horizon 6 調校計算機數學公式模型：底盤懸吊與傳動系統

本文件詳細記錄四種賽事取向（公路/環道、甩尾、越野/拉力、直線加速）下，底盤懸吊（防傾桿、彈簧與車高、阻尼）與傳動系統（差速器及四驅扭力分配）的數學描述與公式模型。所有參數輸入皆基於玩家於遊戲內 UI 介面可直接獲取的具體數值，避免使用隱藏或需經過遙測量測之數據。

本模型的公式基於底盤調校計算機轉換。

1. 基礎變數與 UI 初始輸入定義 (Variables & UI Inputs)

所有底盤與傳動模型所需的初始輸入參數，嚴格限定為遊戲升級與調校選單中可直接讀取的數值。

靜態物理參數：

$W$：車輛總重 ($\text{kg}$)

$W_f\%$：前軸靜態重量分配百分比 ($\%$)

$W_r\%$：後軸靜態重量分配百分比 ($\%$)，滿足 $W_r\% = 100\% - W_f\%$

$Aero_f$：前軸空氣動力下壓力 ($\text{kgf}$) (這一項數值需要替代計算)

$Aero_r$：後軸空氣動力下壓力 ($\text{kgf}$) (這一項數值需要替代計算)

$Drive$：驅動方式 ($\text{FWD}, \text{RWD}, \text{AWD}$)

調校項目邊界條件 (UI Sliders)：

$ARB_{min}, ARB_{max}$：防傾桿極限值，遊戲內預設固定為 $1.0$ 與 $65.0$

$K_{min\_f}, K_{max\_f}$：前彈簧剛性可調範圍最小值與最大值 ($\text{kgf/mm}$)

$K_{min\_r}, K_{max\_r}$：後彈簧剛性可調範圍最小值與最大值 ($\text{kgf/mm}$)

$H_{min\_f}, H_{max\_f}$：前車身高度可調範圍最小值與最大值 ($\text{cm}$)

$H_{min\_r}, H_{max\_r}$：後車身高度可調範圍最小值與最大值 ($\text{cm}$)

$D_{min}, D_{max}$：阻尼極限值，遊戲內預設固定為 $1.0$ 與 $20.0$

$Diff_{min}, Diff_{max}$：差速器鎖定率極限值，固定為 $0\%$ 與 $100\%$

$Center_{min}, Center_{max}$：AWD 中央扭力分配極限值，固定為 $10\%$ 與 $90\%$ (預設指向後軸)

2. 公路/環道 (Road / Circuit)

以最大化彎道橫向抓地力（Lateral Grip）、精確控制循跡煞車與載重轉移為目標，達成極限抓地力與穩定度的泛用底盤模型。

1. 防傾桿 (Anti-Roll Bars, $ARB$)：

標準線性分配法：


$$ARB_f = (ARB_{max} - ARB_{min}) \times \frac{W_f\%}{100} + ARB_{min} = 64.0 \times \frac{W_f\%}{100} + 1.0$$

$$ARB_r = (ARB_{max} - ARB_{min}) \times \frac{W_r\%}{100} + ARB_{min} = 64.0 \times \frac{W_r\%}{100} + 1.0$$

AWD 競賽競技策略 (1/65 Meta 修正)：
若 $Drive = \text{AWD}$ 且追求極限消弭彎中轉向不足，則採用非對稱修正：


$$ARB_f = \min\left(5.0, 1.0 + \frac{W_f\%}{100} \times 4.0\right)$$

$$ARB_r = \max\left(50.0, 65.0 - \left(100\% - W_r\%\right) \times 0.3\right)$$

2. 懸吊彈簧與車高 (Springs & Ride Height, $K, H$)：

基礎彈簧剛性：


$$K_{base\_f} = (K_{max\_f} - K_{min\_f}) \times \frac{W_f\%}{100} + K_{min\_f}$$

$$K_{base\_r} = (K_{max\_r} - K_{min\_r}) \times \frac{W_r\%}{100} + K_{min\_r}$$

空氣動力下壓力補償算式：


$$\Delta K_f = \frac{Aero_f}{10} \times 0.5$$

$$\Delta K_r = \frac{Aero_r}{25} \times 0.5$$

$$K_f = \min\left(K_{max\_f}, K_{base\_f} + \Delta K_f\right)$$

$$K_r = \min\left(K_{max\_r}, K_{base\_r} + \Delta K_r\right)$$

車身高度：
令 $Click = 0.5\text{ cm}$，設定為最低高度加上 2 至 4 個刻度以防止觸底（Bottoming Out）：


$$H_f = H_{min\_f} + 3 \times Click$$

$$H_r = H_{min\_r} + 3 \times Click$$

3. 阻尼系統 (Damping, $D_{reb}, D_{bmp}$)：

回彈阻尼 (Rebound)：


$$D_{reb\_f} = (D_{max} - D_{min}) \times \frac{W_f\%}{100} + D_{min} = 19.0 \times \frac{W_f\%}{100} + 1.0$$

$$D_{reb\_r} = (D_{max} - D_{min}) \times \frac{W_r\%}{100} + D_{min} = 19.0 \times \frac{W_r\%}{100} + 1.0$$

壓縮阻尼 (Bump)（黃金比例 60%）：


$$D_{bmp\_f} = D_{reb\_f} \times 0.60$$

$$D_{bmp\_r} = D_{reb\_r} \times 0.60$$

4. 差速器與扭力分配 (Differential & Center Split)：

FWD (前驅)：


$$Accel_f = 40\%, \quad Decel_f = 10\%$$

RWD (後驅)：


$$Accel_r = \min\left(65\%, \max\left(40\%, 40\% + \frac{W_r\% - 50\%}{100} \times 50\right)\right), \quad Decel_r = 20\%$$

AWD (四驅)：


$$Accel_f = 15\%, \quad Decel_f = 0\%$$

$$Accel_r = 75\%, \quad Decel_r = 15\%$$

$$T_{center\_rear} = \min\left(85\%, \max\left(60\%, W_r\% + 20\%\right)\right)$$

3. 甩尾 (Drift)

針對維持最大反打轉向角（Counter-Steer Angle）與穩定後軸滑移角（Slip Angle）設計，前軸追求順應性貼地，後軸強迫打破抓地力。

1. 防傾桿 (Anti-Roll Bars, $ARB$)：
極端「前軟後硬」設定，前防傾桿釋放前輪獨立懸吊行程，後防傾桿增加後軸剛性：


$$ARB_f = 10.0$$

$$ARB_r = 50.0$$

2. 懸吊彈簧與車高 (Springs & Ride Height, $K, H$)：

甩尾軟化彈簧算式：


$$K_f = \max\left(K_{min\_f}, W \times \frac{W_f\%}{100} \times 0.035\right)$$

$$K_r = \max\left(K_{min\_r}, W \times \frac{W_r\%}{100} \times 0.035\right)$$

車身高度：
前車高略高於後車高以維持物理幾何前抓地力：


$$H_f = H_{min\_f} + 1 \times Click$$

$$H_r = H_{min\_r}$$

3. 阻尼系統 (Damping, $D_{reb}, D_{bmp}$)：
採用低剛性且前後對稱拉平設定，延緩動態響應，防止連續擺動過快造成 Spin-out：


$$D_{reb\_f} = D_{reb\_r} = 6.0$$

$$D_{bmp\_f} = D_{bmp\_r} = D_{reb\_f} \times 0.50 = 3.0$$

4. 差速器與扭力分配 (Differential & Center Split)：

RWD (後驅甩尾)：


$$Accel_r = 100\%, \quad Decel_r = 25\%$$

AWD (四驅甩尾)：


$$Accel_f = 40\%, \quad Decel_f = 0\%$$

$$Accel_r = 100\%, \quad Decel_r = 0\%$$

$$T_{center\_rear} = 88\%$$

4. 拉力/越野 (Rally / Off-Road)

著重於非鋪裝路面（泥地、沙地、飛躍落地）上的懸吊吞吐量（Suspension Travel）與衝擊吸收能力，確保輪胎緊貼地面。

1. 防傾桿 (Anti-Roll Bars, $ARB$)：
全面軟化防傾桿，使兩側懸吊高度獨立運作以吸收地形顛簸：


$$ARB_f = \left(64.0 \times \frac{W_f\%}{100} + 1.0\right) \times 0.35$$

$$ARB_r = \left(64.0 \times \frac{W_r\%}{100} + 1.0\right) \times 0.35$$

2. 懸吊彈簧與車高 (Springs & Ride Height, $K, H$)：

越野低剛性彈簧算式：
令 $K_{base\_f}$ 與 $K_{base\_r}$ 為公路賽基礎彈簧值：


$$K_f = \max\left(K_{min\_f}, K_{base\_f} \times 0.65\right)$$

$$K_r = \max\left(K_{min\_r}, K_{base\_r} \times 0.65\right)$$

車身高度：
調至最大車身高度，提供最大下沉行程：


$$H_f = H_{max\_f}$$

$$H_r = H_{max\_r}$$

3. 阻尼系統 (Damping, $D_{reb}, D_{bmp}$)：
降低回彈阻尼，並大幅降至 40% 的壓縮/回彈比，以快速吸收飛躍落地衝擊：


$$D_{reb\_f} = 14.0 \times \frac{W_f\%}{100} + 1.0$$

$$D_{reb\_r} = 14.0 \times \frac{W_r\%}{100} + 1.0$$

$$D_{bmp\_f} = D_{reb\_f} \times 0.40$$

$$D_{bmp\_r} = D_{reb\_r} \times 0.40$$

4. 差速器與扭力分配 (Differential & Center Split)：
針對鬆散路面低抓地力，大幅提升差速器鎖定率：

RWD (後驅拉力)：


$$Accel_r = 75\%, \quad Decel_r = 25\%$$

AWD (四驅拉力)：


$$Accel_f = 40\%, \quad Decel_f = 10\%$$

$$Accel_r = 80\%, \quad Decel_r = 25\%$$

$$T_{center\_rear} = 65\%$$

5. 直線加速 (Drag)

以 1/4 英里 (400m) 加速時的縱向動態過載抑制與車頭下壓力/氣流姿態最佳化為目標，兼顧起步抓地力與高速穩定度。

1. 防傾桿 (Anti-Roll Bars, $ARB$)：
完全解除前軸防傾桿約束，後軸拉至上限以強烈抑制引擎馬力輸出導致的扭力歪斜（Torque Twist）：


$$ARB_f = 1.0$$

$$ARB_r = 65.0$$

2. 懸吊彈簧與車高 (Springs & Ride Height, $K, H$)：

載重蹲下過載抑制彈簧算式：
前彈簧適度偏軟以允許彈射起步抬頭，後彈簧極硬 (90%) 以承受起步瞬間巨大的動態縱向載重蹲下過載：


$$K_f = K_{min\_f} + 0.20 \times (K_{max\_f} - K_{min\_f})$$

$$K_r = K_{min\_r} + 0.90 \times (K_{max\_r} - K_{min\_r})$$

前傾氣姿態 (Forward Rake Ride Height)：
前車高最低以降低迎風風阻與氣流抬升力，後車高最高以壓實後輪空氣動力姿態：


$$H_f = H_{min\_f}$$

$$H_r = H_{max\_r}$$

3. 阻尼系統 (Damping, $D_{reb}, D_{bmp}$)：
前軸偏軟允許車頭無阻力延伸抬頭，後軸調硬以吸收並平抑起步蹲下的劇烈衝擊：


$$D_{reb\_f} = 3.0, \quad D_{bmp\_f} = 4.0$$

$$D_{reb\_r} = 12.0, \quad D_{bmp\_r} = 10.0$$

4. 差速器與扭力分配 (Differential & Center Split)：

驅動軸加速鎖定率：


$$Accel_f = \begin{cases} 100\% & \text{若為 FWD 或 AWD} \\ 0\% & \text{若為 RWD} \end{cases}, \quad Decel_f = 0\%$$

$$Accel_r = \begin{cases} 100\% & \text{若為 RWD 或 AWD} \\ 0\% & \text{若為 FWD} \end{cases}, \quad Decel_r = 0\%$$

AWD 中央扭力分配：


$$T_{center\_rear} = 80\%$$

6. 補充說明與極限邊界條件

彈簧單位換算：
若遊戲內介面選用英制單位 ($\text{lbf/in}$)，可透過下列換算係數轉換為公制 ($\text{kgf/mm}$) 計算後再輸出：


$$1\text{ kgf/mm} \approx 55.997\text{ lbf/in}$$

滑桿數值安全鉗制 (Safety Clamping)：
所有推導出之參數值，在輸出至實際遊戲 UI 之前，皆必須進行邊界條件檢查：


$$Parameter_{final} = \min\left(Slider_{max}, \max\left(Slider_{min}, Parameter_{calculated}\right)\right)$$

AWD 中央扭力分配與防傾桿互動關係：
當 AWD 中央扭力分配 $T_{center\_rear} > 75\%$ 時，車輛橫向轉向特性將大幅偏向後驅車（RWD）。此時公路賽事中的前防傾桿 $ARB_f$ 可適度從 Meta 1.0 值提升至 $10.0 \sim 15.0$，以取得更平穩的入彎姿態。

附錄：空氣動力下壓力自動解析與推導機制 (resolveAeroDownforce)
若車輛 UI 未提供明確下壓力數值 ($Aero \le 0$)，調校系統將採用「總下壓力經驗估算 + 驅動方式偏置修正」自動推導前後軸下壓力：

1. 驅動方式修正係數 ($DrivetrainModifier$)：
- RWD (後驅)：$0.82$（增加後軸下壓力配比以穩固出彎抓地）
- FWD / AWD (前驅與四驅)：$1.05$（增加前軸下壓力配比以壓制高速推頭）

2. 下壓力分配比率 ($Ratio$)：
$$Ratio = \frac{W_f\%}{W_r\%} \times DrivetrainModifier$$

3. 雙項缺失自動解算 ($Aero_f \le 0$ 且 $Aero_r \le 0$)：
目標總下壓力取車重磅數 ($W_{lbs} = W_{kg} \times 2.20462$) 的 20%：
$$Aero_{total\_kgf} = \frac{W_{lbs} \times 0.20}{2.20462}$$

解聯立方程：
$$Aero_r = \frac{Aero_{total\_kgf}}{1 + Ratio}, \quad Aero_f = Aero_{total\_kgf} - Aero_r$$
