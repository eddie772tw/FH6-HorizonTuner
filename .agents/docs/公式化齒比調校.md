# 齒比模型與單位責任

正式公式在 Rust `backend-rust/src/tuning/gearing/`，UI 不提供公式或 fallback。舊版推導、TypeScript 凍結實作及已退役 solver 僅保留於 Git 歷史，不應從舊說明重建成新的計算入口。

| 目標 | 現行版本 | 必要語意 |
| --- | --- | --- |
| Road | launch-envelope/v3 | 起步／末檔總比與來源明確的工程先驗 |
| Rally | rally-joint/v1 | 自己的目標與聯合齒比配置，不套 Road 收尾 |
| Drift | drift-working/v1 | 使用者主檔、RPM、輪速；缺值不可算牌 |
| Drag | drag-joint/v1 | 起步／末速共同約束，保留明確目標與不可行原因 |

DangerSign 僅沿用必要現行路徑，不新增第五個模型或獨立項目。輪軸、輪徑、參考與有效 RPM 由後端提供；純滾動輪速不等於滑移地速。

後端保存推薦時重播合格原始證據並比對；退役版本只能檢視／匯出原始封存。重新計算建立新記錄，不能改標籤、補造量測或沿用舊資格。等價重配必須重驗原目標與 observed 範圍。

開發依 [physics-tuning-math](../skills/physics-tuning-math/SKILL.md)；版本與資料處理見[現行契約](../../docs/tuning/aego-version-contract.md)及[封存說明](../../docs/tuning/model-retirement.md)。歷史推導可查 [#657 固定來源](https://github.com/eddie772tw/FH6-HorizonTuner/tree/2c72bed878b84d40ba47ec5c41edaa16fa9157ce)。
