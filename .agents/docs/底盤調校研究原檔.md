Forza Horizon 系列模擬物理下之懸吊、彈簧阻尼、防傾桿與差速器多賽事目標公式化調校體系研究在《Forza Horizon》系列（包含 FH5 與 FH6）的物理模擬架構中，底盤懸吊與傳動系統的調校本質上是一套建構於多體動力學（Multibody Dynamics）與簡化物理模型之上的數值矩陣。車輛在賽道上的動態響應——包含轉向特性、載重轉移速率、輪胎接觸面維持能力以及彎道極限——皆由使用者於調校選單中輸入的參數直接決定。為滿足玩家在不同競賽情境下的性能需求，調校公式不能再使用單一的極限抓地力（Grip）邏輯，而必須依據四種核心賽事目標——公路/環道（Road / Circuit）、甩尾（Drift）、越野/拉力（Off-Road / Rally） 以及 直線加速（Drag）——進行數學公式與物理邏輯的動態調整。本研究針對「防傾桿（Anti-Roll Bars, ARBs）」、「懸吊彈簧與車身高度（Springs & Ride Height）」、「阻尼（Damping）」以及「差速器（Differential）」四大分頁，整合驅動方式（FWD、RWD、AWD）與 AWD 中央扭力分配（Center Differential Torque Split），導出完全以遊戲 UI 可視數據為初始輸入的四維動態數學模型。一、導論與四維賽事目標調校架構變數為確保調校公式的可執行性與重複性，計算模型的初始輸入變數嚴格限制於玩家在車輛升級選單與調校介面中可直接讀取的數值，徹底避免採用如滾動中心高度（Roll Center Height）或隱藏胎壁剛性等無法直接量化的數據。遊戲內 UI 可直接查詢的核心初始輸入變數包括：車輛靜態物理數據：車輛總重（Total Weight, $W$）、前軸靜態重量分配百分比（Front Weight Bias, $W_f\%$）、後軸靜態重量分配百分比（Rear Weight Bias, $W_r\% = 100\% - W_f\%$）、前後空氣動力下壓力（Aerodynamic Downforce, $Aero_f$ 與 $Aero_r$）。Slider 邊界條件：各調校項目拖曳至左右端點時顯示的最小值（$Min$）與最大值（$Max$）。在推導公式前，必須針對四大調校分頁中各參數的邊界條件進行分類：調校分頁參數名稱物理單位Slider 上下限範圍特性典型數值範圍（公制 / 英制）變數影響因子與來源防傾桿 (ARBs)前 / 後防傾桿剛性無單位純數固定數值$1.0 \sim 65.0$全車系與各級升級套件皆維持固定 $1.0$ 至 $65.0$ 軸線。懸吊彈簧 (Springs)前 / 後彈簧剛性$\text{kgf/mm}$ / $\text{lbf/in}$動態變化依車重與套件而定（如 $30.0 \sim 250.0 \text{ kgf/mm}$）上下限受車輛總重、基底結構及懸吊等級（Race/Rally/Drift）決定。懸吊彈簧 (Springs)前 / 後車身高度$\text{cm}$ / $\text{in}$動態變化依車型懸吊幾何而定最低與最高高度受限於車型輪拱與懸吊行程結構。阻尼 (Damping)前 / 後回彈阻尼 (Rebound)無單位純數固定數值$1.0 \sim 20.0$配備可調懸吊時固定為 $1.0$ 至 $20.0$。阻尼 (Damping)前 / 後壓縮阻尼 (Bump)無单位純數固定數值$1.0 \sim 20.0$配備可調懸吊時固定為 $1.0$ 至 $20.0$。差速器 (Differential)加速 / 減速鎖定率百分比 ($\%$)固定數值$0\% \sim 100\%$所有驅動型式與可調差速器零件皆為 $0\%$ 至 $100\%$。差速器 (Differential)中央扭力分配 (Center Split)百分比 ($\%$)固定數值$10\% \sim 90\%$僅限四輪驅動（AWD）配備賽車中央差速器時解鎖。二、公路/環道賽（Road / Circuit Racing）之公式化極限抓地力調校公路賽事的調校核心在於最大化彎道橫向抓地力（Lateral Grip）與維持車輛動態平穩，減少車身側傾對輪胎接觸面的破壞，並精確控制循跡煞車（Trail Braking）與出彎加速時的載重轉移。1. 防傾桿（ARBs）算式採用靜態重量分配線性內插法，配合前後軸載重比建立基準剛性：$$ARB_f = (ARB_{max} - ARB_{min}) \times W_f\% + ARB_{min} = 64.0 \times W_f\% + 1.0$$$$ARB_r = (ARB_{max} - ARB_{min}) \times W_r\% + ARB_{min} = 64.0 \times W_r\% + 1.0$$AWD 競賽偏置（Meta 1/65 策略）：若採用四輪驅動（AWD），為消除前軸拉力導致的彎中轉向不足，主流極限算式會改採非對稱極端設定：$ARB_f = 1.0 \sim 5.0$，$ARB_r = 50.0 \sim 65.0$。2. 懸吊彈簧（Springs）與車身高度算式彈簧需負擔車重與高車速下的空氣動力下壓力。基礎彈簧剛性（內插法）：$$K_f = (K_{max\_f} - K_{min\_f}) \times W_f\% + K_{min\_f}$$$$K_r = (K_{max\_r} - K_{min\_r}) \times W_r\% + K_{min\_r}$$下壓力補償算式（英制磅）：$$\Delta K_f = \frac{Aero_f}{10} \times 0.5, \quad \Delta K_r = \frac{Aero_r}{25} \times 0.5$$[cite: 2, 11]$$K_{f\_final} = K_f + \Delta K_f, \quad K_{r\_final} = K_r + \Delta K_r$$車身高度：調至最低（$Min$）後往右加 $2 \sim 4$ 個點擊（Clicks），降低重心高度並防止觸底。3. 阻尼系統（Damping）算式公路賽事強調諧振抑制與快速載重轉移，維持 $60\%$ ($0.60$) 的壓縮/回彈黃金比例：$$D_{reb\_f} = 19.0 \times W_f\% + 1.0, \quad D_{reb\_r} = 19.0 \times W_r\% + 1.0$$$$D_{bmp\_f} = D_{reb\_f} \times 0.60, \quad D_{bmp\_r} = D_{reb\_r} \times 0.60$$4. 差速器（Differential）設定FWD：加速鎖定率 $30\% \sim 50\%$，減速鎖定率 $0\% \sim 15\%$。RWD：加速鎖定率 $40\% \sim 65\%$，減速鎖定率 $15\% \sim 30\%$。AWD：前軸 15/0%（加速/減速），後軸 75/15%。中央扭力分配公式：
$$T_{center\_rear} = W_r\% + 20\% \quad (\text{標竿設定：} 70\% \sim 75\% \text{ 後軸偏置})$$[cite: 2, 9, 12, 14]三、甩尾賽（Drift）之轉向角度與過渡擺動算式甩尾調校的物理邏輯與公路賽相反：前軸必須具備極高指向性與 compliance（順應性）以維持最大反打轉向角（Counter-Steer Angle），後軸則必須極易突破靜摩擦力並保持穩定的滑移角（Slip Angle）。1. 防傾桿（ARBs）算式甩尾防傾桿的核心在於創造前後軸剛性的極端不平衡，前軟後硬：$$ARB_f = 10.0 \quad (\text{範圍 } 1.0 \sim 20.0)$$[cite: 6, 18, 21]$$ARB_r = 50.0 \quad (\text{範圍 } 40.0 \sim 65.0)$$[cite: 6, 18]物理作用：前防傾桿調軟使前車頭在傾側時能保持前輪輪胎接觸面貼地（極限反打）；後防傾桿大幅加硬可快速扭轉後軸，強迫內側後輪橫向載重劇烈轉移而打滑，且使後軸動態呈現一致性擺動。2. 懸吊彈簧（Springs）與車身高度算式甩尾需要較軟且平衡的彈簧平台，以延緩動態響應，使車輛在左右連續甩尾過渡（Transitions）時姿態平緩可控。甩尾專用彈簧推導公式（以英制磅 $W_{lb}$ 為基準）：$$K_{drift\_f} = W_{lb} \times W_f\% \times 0.15$$$$K_{drift\_r} = W_{lb} \times W_r\% \times 0.15$$
(公制 $\text{kgf/mm}$ 單位下，係數可透過線性縮放至約 $40.0 \sim 80.0 \text{ kgf/mm}$ 區間，前後剛性保持接近 $1:1$ 比率)。車身高度：前後皆降至最低（$Min$），但前車身高度可往右加 $1$ 個點擊（提升前軸物理幾何抓地，輔助控制角度）。3. 阻尼系統（Damping）算式甩尾阻尼採用低剛性且對稱的軟調設定，防止懸吊擺動太快導致車身瞬間甩過頭（Snap Oversteer）：$$D_{reb\_f} = D_{reb\_r} = 4.0 \sim 8.0 \quad (\text{全車回彈阻尼拉平於低位})$$[cite: 6, 21]$$D_{bmp\_f} = D_{bmp\_r} = D_{reb} \times 0.50 \quad (\text{壓縮阻尼約伸展阻尼的 } 50\%)$$4. 差速器（Differential）設定RWD 甩尾：加速鎖定率 $95\% \sim 100\%$（接近或完全鎖定），減速鎖定率 $20\% \sim 30\%$。100% 的加速鎖定能確保踩下油門時左右後輪強迫同速旋轉，瞬間打破後軸抓地力。AWD 甩尾：前軸加速/減速（40%/0%），後軸加速/減速（100%/0%）。AWD 中央扭力分配：$$T_{center\_rear} = 85\% \sim 90\% \text{ Rear}$$
[cite: 7, 13, 18]
讓 $85\%$ 以上的動力持續輸送至後軸以維持甩尾姿態，前軸僅保留少量拉力用於在極大角度下將車輛拉出彎道防止自轉（Spin-out）。四、越野/拉力賽（Off-Road / Rally）之懸吊吞吐量與鬆散路面鎖定率算式越野與拉力調校的核心在於最大化懸吊行程吞吐量（Suspension Travel）與衝擊吸收能力，確保車輛在跳躍落地、飛頂（Crests）與泥地/沙地顛簸時輪胎仍能緊貼地面。1. 防傾桿（ARBs）算式越野賽事需要左右兩側懸吊具備高度獨立運作的能力，防傾桿若太硬，單側車輪撞擊石塊時會將衝力傳遞至整輛車造成劇烈彈跳。因此防傾桿需全面軟化：$$ARB_{rally\_f} = (64.0 \times W_f\% + 1.0) \times 0.35 \approx 22.4 \times W_f\% + 0.35$$$$ARB_{rally\_r} = (64.0 \times W_r\% + 1.0) \times 0.35 \approx 22.4 \times W_r\% + 0.35$$典型數值範圍設定於 $10.0 \sim 25.0$ 之間，且後防傾桿可適度加硬以輔助在低抓地力鬆散路面上切入彎道。2. 懸吊彈簧（Springs）與車身高度算式絕對質量基礎彈簧剛性：$$K_{base\_f} = \frac{W}{2} \times W_f\%, \quad K_{base\_r} = \frac{W}{2} \times W_r\%$$
越野/拉力設定僅在 $K_{base}$ 上加入 $10\% \sim 20\%$ ($1.10 \sim 1.20$) 的剛性增益，大幅降低彈簧硬度以允許懸吊充分壓縮吸收衝擊：
$$K_{rally\_f} = K_{base\_f} \times 1.15, \quad K_{rally\_r} = K_{base\_r} \times 1.15$$[cite: 8]車身高度：設定至最高（$Max$）或接近最高，為懸吊提供最大的下沉與壓縮行程，防止車底板撞擊地面。3. 阻尼系統（Damping）算式拉力賽事需要極低且反應迅速的壓縮阻尼以吸收飛躍落地的衝擊，同時需要適中的回彈阻尼控制彈簧釋放。壓縮/回彈比例下降至 $35\% \sim 50\%$：$$D_{reb\_f} = 14.0 \times W_f\% + 1.0, \quad D_{reb\_r} = 14.0 \times W_r\% + 1.0$$$$D_{bmp\_f} = D_{reb\_f} \times 0.40, \quad D_{bmp\_r} = D_{reb\_r} \times 0.40$$4. 差速器（Differential）設定鬆散路面（沙地、草地、泥地）抓地力極低，單側車輪極易打滑，因此差速器鎖定率必須大幅高於公路賽事，強迫雙側車輪同步輸出：RWD 拉力：加速鎖定率 $65\% \sim 85\%$，減速鎖定率 $20\% \sim 35\%$。AWD 拉力：前軸加速/減速（40%/10%），後軸加速/減速（80%/25%）。AWD 中央扭力分配：$$T_{center\_rear} = 60\% \sim 70\% \text{ Rear}$$
拉力賽事不需要極端的後軸偏置，較為平均的扭力分配（如 $65\%$ 後 / $35\%$ 前）能在鬆散路面提供最佳的四輪抓地力與直線推進力。五、直線加速賽（Drag Racing）之縱向載重轉移與彈性形變矩陣直線加速的唯一目標是起步瞬間（Launch）與前段加速的縱向牽引力最大化，利用物理學上的動態載重後移（Pitch/Weight Transfer），將全車質量壓在後驅動輪上。1. 防傾桿（ARBs）算式直線加速不需要抵抗橫向側傾，反而需要完全釋放前後軸的軸向自由度以利載重後移：$$ARB_f = 1.0 \quad (\text{完全解除前防傾桿抵抗})$$[cite: 5, 23]$$ARB_r = 1.0 \sim 10.0 \quad (\text{後防傾桿保持極低，確保兩側後輪均勻壓地})$$[cite: 5, 23]2. 懸吊彈簧（Springs）與車身高度算式直線加速採用極端的幾何非對稱懸吊構型，強迫車尾在起步時下沉（Squat），車頭抬升：彈簧剛性：前彈簧調至極硬以阻止起步後車頭下沉，後彈簧調至極軟以允許起步瞬間車尾快速蹲下壓實後輪：
$$K_{drag\_f} = K_{max\_f} \times 0.90 \quad (\text{接近最大值})$$$$K_{drag\_r} = K_{min\_r} \quad (\text{調至最小值})$$車身高度：前車身高度調至最高（$Max$），後車身高度調至最低（$Min$）。此物理傾角（Rake）直接改變了靜態重心位置，起步瞬間能產生最大的縱向滾動槓桿效應。3. 阻尼系統（Damping）算式阻尼器的非對稱設定是 Drag 調校的精髓，精確控制重量轉移發生的單向速率：前軸阻尼：前回彈阻尼調至最低（$D_{reb\_f} = 1.0$），允許前懸吊無阻力拉伸抬頭；前壓縮阻尼調至最高（$D_{bmp\_f} = 20.0$），防止車頭下沉。後軸阻尼：後壓縮阻尼調至最低（$D_{bmp\_r} = 1.0$），允許後懸吊無阻力壓縮蹲下；後回彈阻尼調至最高（$D_{reb\_r} = 20.0$），起步蹲下後鎖死後懸吊，防止車尾彈起釋放抓地力。4. 差速器（Differential）設定加速鎖定率（所有驅動型式）：$100\%$（絕對鎖定）。起步時不容許任何兩輪轉速差，確保所有引擎扭力 $100\%$ 轉化為縱向推力。減速鎖定率：$0\%$。AWD 中央扭力分配：$$T_{center\_rear} = 75\% \sim 85\% \text{ Rear}$$
