# Forza Horizon 系列模擬物理下之懸吊、彈簧阻尼、防傾桿與差速器多賽事目標公式化調校體系研究

在《Forza Horizon》系列（包含 FH5 與 FH6）的物理模擬架構中，底盤懸吊與傳動系統的調校本質上是一套建構於多體動力學（Multibody Dynamics）與簡化物理模型之上的數值矩陣。車輛在賽道上的動態響應——包含轉向特性、載重轉移速率、輪胎接觸面維持能力以及彎道極限——皆由使用者於調校選單中輸入的參數直接決定。

為滿足玩家在不同競賽情境下的性能需求，調校公式不能再使用單一的極限抓地力（Grip）邏輯，而必須依據四種核心賽事目標——**公路/環道（Road / Circuit）**、**甩尾（Drift）**、**越野/拉力（Off-Road / Rally）** 以及 **直線加速（Drag）**——進行數學公式與物理邏輯的動態調整。本研究針對「防傾桿（Anti-Roll Bars, ARBs）」、「懸吊彈簧與車身高度（Springs & Ride Height）」、「阻尼（Damping）」以及「差速器（Differential）」四大分頁，整合驅動方式（FWD、RWD、AWD）與 AWD 中央扭力分配（Center Differential Torque Split），導出完全以遊戲 UI 可視數據為初始輸入的四維動態數學模型。

---

## 一、導論與四維賽事目標調校架構變數

為確保調校公式的可執行性與重複性，計算模型的初始輸入變數嚴格限制於玩家在車輛升級選單與調校介面中可直接讀取的數值，徹底避免採用如滾動中心高度（Roll Center Height）或隱藏胎壁剛性等無法直接量化的數據。

### 遊戲內 UI 可直接查詢的核心初始輸入變數包括：
* **車輛靜態物理數據**：車輛總重（Total Weight, $W$）、前軸靜態重量分配百分比（Front Weight Bias, $W_f\%$）、後軸靜態重量分配百分比（Rear Weight Bias, $W_r\% = 100\% - W_f\%$）、前後空氣動力下壓力（Aerodynamic Downforce, $Aero_f$ 與 $Aero_r$）。
* **Slider 邊界條件**：各調校項目拖曳至左右端點時顯示的最小值（$Min$）與最大值（$Max$）。

### 各參數邊界條件與特性分類表：
| 調校分頁 | 參數名稱 | 物理單位 | Slider 上下限範圍特性 | 典型數值範圍（公制 / 英制） | 變數影響因子與來源 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 防傾桿 (ARBs) | 前 / 後防傾桿剛性 | 無單位純數 | 固定數值 | $1.0 \sim 65.0$ | 全車系與各級升級套件皆維持固定 $1.0$ 至 $65.0$ 軸線。 |
| 懸吊彈簧 (Springs) | 前 / 後彈簧剛性 | $\text{kgf/mm}$ / $\text{lbf/in}$ | 動態變化 | 依車重與套件而定 | 上下限受車輛總重、基底結構及懸吊等級（Race/Rally/Drift）決定。 |
| 懸吊彈簧 (Springs) | 前 / 後車身高度 | $\text{cm}$ / $\text{in}$ | 動態變化 | 依車型懸吊幾何而定 | 最低與最高高度受限於車型輪拱與懸吊行程結構。 |
| 阻尼 (Damping) | 前 / 後回彈阻尼 (Rebound) | 無單位純數 | 固定數值 | $1.0 \sim 20.0$ | 配備可調懸吊時固定為 $1.0$ 至 $20.0$。 |
| 阻尼 (Damping) | 前 / 後壓縮阻尼 (Bump) | 無單位純數 | 固定數值 | $1.0 \sim 20.0$ | 配備可調懸吊時固定為 $1.0$ 至 $20.0$。 |
| 差速器 (Differential) | 加速 / 減速鎖定率 | 百分比 ($\%$) | 固定數值 | $0\% \sim 100\%$ | 所有驅動型式與可調差速器零件皆為 $0\%$ 至 $100\%$。 |
| 差速器 (Differential) | 中央扭力分配 (Center Split) | 百分比 ($\%$) | 固定數值 | $10\% \sim 90\%$ | 僅限四輪驅動（AWD）配備賽車中央差速器時解鎖。 |

## 二、公路/環道賽（Road / Circuit Racing）之公式化極限抓地力調校

公路賽事的調校核心在於最大化彎道橫向抓地力（Lateral Grip）與維持車輛動態平穩，減少車身側傾對輪胎接觸面的破壞，並精確控制循跡煞車（Trail Braking）與出彎加速時的載重轉移。

1. **防傾桿（ARBs）算式**：
   採用靜態重量分配線性內插法：
   $$ARB_f = (ARB_{max} - ARB_{min}) \times \frac{W_f\%}{100} + ARB_{min} = 64.0 \times \frac{W_f\%}{100} + 1.0$$
   $$ARB_r = (ARB_{max} - ARB_{min}) \times \frac{W_r\%}{100} + ARB_{min} = 64.0 \times \frac{W_r\%}{100} + 1.0$$
   
   **AWD 競賽偏置（Meta 1/65 策略）**：
   若採用四輪驅動（AWD），為消除前軸拉力導致的彎中轉向不足，改採非對稱極端設定：
   $$ARB_f = \min\left(5.0, 1.0 + \frac{W_f\%}{100} \times 4.0\right)$$
   $$ARB_r = \max\left(50.0, 65.0 - (100 - W_r) \times 0.3\right)$$

2. **懸吊彈簧（Springs）與車身高度算式**：
   基礎彈簧剛性（內插法）：
   $$K_{base\_f} = (K_{max\_f} - K_{min\_f}) \times \frac{W_f\%}{100} + K_{min\_f}$$
   $$K_{base\_r} = (K_{max\_r} - K_{min\_r}) \times \frac{W_r\%}{100} + K_{min\_r}$$
   
   空氣動力下壓力補償算式：
   $$\Delta K_f = \frac{Aero_f}{10} \times 0.5, \quad \Delta K_r = \frac{Aero_r}{25} \times 0.5$$
   $$K_{f} = K_{base\_f} + \Delta K_f, \quad K_{r} = K_{base\_r} + \Delta K_r$$
   
   車身高度：調至最低（$H_{min}$）後往右加 3 個刻度（Clicks, $Click = 0.5\text{ cm}$），防極限觸底。

3. **阻尼系統（Damping）算式**：
   回彈阻尼 ($D_{reb}$)：
   $$D_{reb\_f} = 19.0 \times \frac{W_f\%}{100} + 1.0, \quad D_{reb\_r} = 19.0 \times \frac{W_r\%}{100} + 1.0$$
   壓縮阻尼 ($D_{bmp}$) (黃金比例 60%)：
   $$D_{bmp\_f} = D_{reb\_f} \times 0.60, \quad D_{bmp\_r} = D_{reb\_r} \times 0.60$$

4. **差速器（Differential）設定**：
   - **FWD**：加速 $40\%$，減速 $10\%$。
   - **RWD**：加速 $\min\left(65\%, \max\left(40\%, 40\% + (W_r - 50) \times 0.5\right)\right)$，減速 $20\%$。
   - **AWD**：前軸加速 15% / 減速 0%，後軸加速 75% / 減速 15%。
   - **AWD 中央扭力分配**：
     $$T_{center\_rear} = \min\left(85\%, \max\left(60\%, W_r\% + 20\%\right)\right)$$

## 三、甩尾賽（Drift）之轉向角度與過渡擺動算式

甩尾調校的物理邏輯與公路賽相反：前軸必須具備極高指向性與 compliance（順應性）以維持最大反打轉向角，後軸則必須極易突破靜摩擦力並保持穩定的滑移角。

1. **防傾桿（ARBs）算式**：
   極端前軟後硬：
   $$ARB_f = 10.0, \quad ARB_r = 50.0$$

2. **懸吊彈簧（Springs）與車身高度算式**：
   $$K_f = W \times \frac{W_f\%}{100} \times 0.035, \quad K_r = W \times \frac{W_r\%}{100} \times 0.035$$
   車身高度：前高於後一個刻度 ($H_f = H_{min\_f} + 0.5\text{ cm}, H_r = H_{min\_r}$)。

3. **阻尼系統（Damping）算式**：
   低剛性且對稱拉平：
   $$D_{reb\_f} = D_{reb\_r} = 6.0, \quad D_{bmp\_f} = D_{bmp\_r} = 3.0$$

4. **差速器（Differential）設定**：
   - **RWD**：加速 $100\%$，減速 $25\%$。
   - **AWD**：前軸加速 40% / 減速 0%，後軸加速 100% / 減速 0%，中央分配 $T_{center\_rear} = 88\%$。

## 四、越野/拉力賽（Off-Road / Rally）之懸吊吞吐量與鬆散路面鎖定率算式

越野與拉力調校的核心在於最大化懸吊行程吞吐量與衝擊吸收能力，確保車輛在跳躍落地與泥地/沙地顛簸時輪胎緊貼地面。

1. **防傾桿（ARBs）算式**：
   防傾桿整體軟化 35%：
   $$ARB_f = \left(64.0 \times \frac{W_f\%}{100} + 1.0\right) \times 0.35$$
   $$ARB_r = \left(64.0 \times \frac{W_r\%}{100} + 1.0\right) \times 0.35$$

2. **懸吊彈簧（Springs）與車身高度算式**：
   $$K_f = K_{base\_f} \times 0.65, \quad K_r = K_{base\_r} \times 0.65$$
   車身高度：調至最高 ($H_f = H_{max\_f}, H_r = H_{max\_r}$)。

3. **阻尼系統（Damping）算式**：
   降低回彈阻尼，並大幅降至 40% 壓縮/回彈比：
   $$D_{reb\_f} = 14.0 \times \frac{W_f\%}{100} + 1.0, \quad D_{reb\_r} = 14.0 \times \frac{W_r\%}{100} + 1.0$$
   $$D_{bmp\_f} = D_{reb\_f} \times 0.40, \quad D_{bmp\_r} = D_{reb\_r} \times 0.40$$

4. **差速器（Differential）設定**：
   - **RWD**：加速 $75\%$，減速 $25\%$。
   - **AWD**：前軸加速 40% / 減速 10%，後軸加速 80% / 減速 25%，中央分配 $T_{center\_rear} = 65\%$。

## 五、直線加速賽（Drag Racing）之縱向載重過載與氣流姿態矩陣

直線加速的唯一目標是 1/4 英里 (400m) 加速時的縱向動態過載抑制與車頭下壓力/氣流姿態最佳化，兼顧起步抓地力與高速穩定度。

1. **防傾桿（ARBs）算式**：
   完全解除前軸防傾桿約束，後軸拉至最大值 65.0 以強烈抑制引擎馬力輸出導致的扭力歪斜（Torque Twist）：
   $$ARB_f = 1.0, \quad ARB_r = 65.0$$

2. **懸吊彈簧（Springs）與車身高度算式**：
   彈簧剛性：前彈簧適度偏軟以允許彈射起步抬頭，後彈簧極硬 (90%) 以承受起步瞬間巨大的動態縱向載重蹲下過載：
   $$K_f = K_{min\_f} + 0.20 \times (K_{max\_f} - K_{min\_f})$$
   $$K_r = K_{min\_r} + 0.90 \times (K_{max\_r} - K_{min\_r})$$
   
   車身高度：採用前低後高前傾氣姿態 (Forward Rake Ride Height)。前車身高度調至最低（$H_{min\_f}$），後車身高度調至最高（$H_{max\_r}$），降低迎風風阻與前軸抬升力，同時壓實後輪空氣動力姿態。

3. **阻尼系統（Damping）算式**：
   前軸偏軟允許車頭無阻力延伸抬頭，後軸調硬以平抑與吸收起步蹲下的劇烈過載：
   $$D_{reb\_f} = 3.0, \quad D_{bmp\_f} = 4.0$$
   $$D_{reb\_r} = 12.0, \quad D_{bmp\_r} = 10.0$$

4. **差速器（Differential）設定**：
   - 驅動軸加速鎖定率：$Accel_f = 100\%$ (FWD/AWD), $Accel_r = 100\%$ (RWD/AWD)，減速鎖定率 $0\%$。
   - AWD 中央扭力分配：$T_{center\_rear} = 80\%$。

## 六、四大賽事目標之全參數公式與調校邏輯綜合對照表

下表統整了在四種不同賽事目標下，以 UI 可視數據（$W, W_f\%, Aero, Slider_{min/max}$）為初始輸入的完整計算公式與參數矩陣：

| 調校項目 | 公路/環道賽 (Road / Circuit) | 甩尾賽 (Drift) | 越野/拉力賽 (Off-Road / Rally) | 直線加速賽 (Drag) |
| :--- | :--- | :--- | :--- | :--- |
| **前防傾桿 ($ARB_f$)** | $64.0 \times W_f\% + 1.0$<br>(AWD 可選 $1.0 \sim 5.0$) | $10.0$ (固定低值) | $(64.0 \times W_f\% + 1.0) \times 0.35$ | $1.0$ (完全解鎖前軸) |
| **後防傾桿 ($ARB_r$)** | $64.0 \times W_r\% + 1.0$<br>(AWD 可選 $50.0 \sim 65.0$) | $50.0$ (固定高值) | $(64.0 \times W_r\% + 1.0) \times 0.35$ | $65.0$ (極硬抑制歪斜) |
| **前彈簧剛性 ($K_f$)** | 內插值 $+ \frac{Aero_f}{10} \times 0.5$ | $W \times W_f\% \times 0.035$ | $K_{base\_f} \times 0.65$ | $K_{min\_f} + 0.20 \Delta K_f$ (適度偏軟) |
| **後彈簧剛性 ($K_r$)** | 內插值 $+ \frac{Aero_r}{25} \times 0.5$ | $W \times W_r\% \times 0.035$ | $K_{base\_r} \times 0.65$ | $K_{min\_r} + 0.90 \Delta K_r$ (極硬防蹲過載) |
| **車身高度 (Ride Height)** | 最低 ($H_{min}$) $+ 3$ Clicks | 前最低 $+ 1$ Click / 後最低 | 最高 ($H_{max}$) | 前最低 ($H_{min\_f}$) / 後最高 ($H_{max\_r}$) |
| **前/後回彈阻尼 ($D_{reb}$)** | $19.0 \times W\% + 1.0$ | 前後拉平：$6.0$ | $14.0 \times W\% + 1.0$ | 前 $3.0$ / 後 $12.0$ |
| **前/後壓縮阻尼 ($D_{bmp}$)** | $D_{reb} \times 0.60$ ($60\%$ 比率) | $D_{reb} \times 0.50$ ($50\%$ 比率) | $D_{reb} \times 0.40$ ($40\%$ 比率) | 前 $4.0$ / 後 $10.0$ |
| **差速器加速鎖定 (RWD)** | $40\% \sim 65\%$ | $100\%$ | $75\%$ | $100\%$ |
| **差速器減速鎖定 (RWD)** | $20\%$ | $25\%$ | $25\%$ | $0\%$ |
| **AWD 扭力分配 (Center)** | $W_r\% + 20\%$ (約 $70\% \sim 75\%$) | $88\%$ 後軸偏置 | $65\%$ 後軸偏置 | $80\%$ 後軸偏置 |

透過上述矩陣，玩家可根據具體的賽事目標，選用對應的公式體系與輸入變數，推算出最適化的底盤與傳動調校參數。
