## 獨立量測方法

先直接檢視原始 PNG，辨認 0、10、20、30、40、50、60、70、80 PSI 的九個白色三角刻度，避免把文字或次刻度當作主刻度。

1. 讀取原始 RGBA 像素，選取 RGB 各通道皆大於 185、alpha 大於 200 的白色像素。
2. 以初始中心 (131.5, 131.5) 建立極座標，在 136° 至 404° 的每個整度 ±0.5° 區間、半徑 112 至 122 內，取半徑最大的白色像素。這些像素屬於連續外圓弧，不是三角刻度中心。
3. 對收集的 (x, y) 以最小平方解 `2x·cx + 2y·cy + c = x² + y²`，得到圓心 (131.5093, 131.4708)，半徑 115.961。採用符合素材左右對稱的半像素圓心 (131.5, 131.5)，而不是整張圖片 bounds 的中心 (132, 133.5)。
4. 對九個主刻度，分別取其粗略方向 ±6°、半徑 107 至 111 的白色像素，計算平均方位角。粗略方向僅用於分離各刻度，最終角度來自像素；此環帶避開外圓弧與內側數字。
5. Canvas 座標為右向 0°、順時針遞增，角度在 120° 起點連續展開，以避免 360° 斷點。

最大誤差小於 0.16°，在量測半徑上不到 0.31 個原始像素。因此使用 135° 起點、270° sweep 與上述圓心，而不是將 raster 誤差過度擬合成非線性刻度。舊 120° 起點、300° sweep 在兩端約有 15° 誤差。

## 驗證入口

- 純幾何測試：`pnpm -C frontend exec vitest run ../hud_overlay/auxiliary_gauges/tests/unit/greddyCalibration.test.ts`
- 前端完整 gate：`pnpm -C frontend run test`（Windows 以 `cmd /c` 包裹）。
- 視覺 fixture：啟動專案 HUD 靜態伺服器後，開啟 `/hud/auxiliary_gauges/tests/visual/greddy-calibration.html`。
- Fixture 的三個 iframe 載入真實 `index.html`、HUDCore、原始 PNG 與產品指針函式，以受控 `gaugeValues.oilPressure` 分別輸入 0、40、80 PSI，保留原有無資料行為。
- 在 Chromium 以 DPR 1 與 2 檢查三個指針方向、刻度位置與圓心。截圖是瀏覽器受控遙測驗證，不是遊戲或 Windows 原生 HUD 截圖。

單元測試只檢查壓力到角度的行為、全刻度量測容差、clamp、連續性與對稱性；不攔截 Canvas 呼叫次數、不對微觀 Canvas 像素座標下斷言。
