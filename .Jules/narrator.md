## 2025-03-09 - Handling Translation Keys in Badges and Statuses
**Learning:** Found that hardcoded English strings like 'OTA', 'DYNAMIC PORT', and 'OFFLINE' were embedded directly in UI badges (in Navigation.tsx and UpdateModal.tsx) and toast notifications (ToastContainer.tsx). These components missed proper i18n wrapping, leading to a mixed-language experience for non-English users. Furthermore, missing translation keys in the fallback system can lead to returning untranslated English strings even if the wrapper exists. Also discovered that the translation JSON files had an invalid syntax ending in the middle of a string structure which was breaking basic parsing.
**Action:** Always verify that badge text and status tags are wrapped in `t()` using the `useSettings` hook. Ensure that when extracting these missing keys, all locale files (including `en-us.json`, `ja-jp.json`, `zh-tw.json`) receive the new keys to prevent fallback failures, and perform JSON syntax validations after any automated modifications.
